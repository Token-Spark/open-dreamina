它是怎么工作的

Open Dreamina 是一个跑在你自己电脑上的 AIGC 创作工具，用浏览器打开就能用。它本身不绑定某一个模型，而是把图片生成和视频生成当作可插拔的服务：你在界面里激活哪一家模型，它就调用哪一家。

这套工具同时附带了一份面向 AI 智能体的指引文件（仓库根目录的 AGENTS.md）。当你把它交给 codex、workbuddy 这类智能体时，智能体会读取这份指引，自动完成环境检查、配置生成、镜像构建和服务启动。你不需要记任何命令，只要把一句话需求发给智能体即可。

所以整条路径被压缩成了两段：智能体负责把工具装好跑起来，你负责在浏览器里写提示词产出素材。下面按顺序讲清楚每一步。

智能体做的事

读 AGENTS.md，检查 Docker 与端口，生成 .env，启动服务并做健康检查。

你做的事

发一句话给智能体；部署完成后在浏览器里配置模型、写提示词、生成素材。

结果存哪里

所有对话、生成记录和素材都落在本地 ./data 目录，不依赖任何云端账号。

准备工作

部署前只需要两样东西：一个能跑容器的 Docker 环境，以及一个能读 AGENTS.md 的 AI 智能体。

Docker 环境

Windows 与 macOS 推荐 Docker Desktop（启动后等左下角显示 Engine running）；Linux 用 Docker Engine。确保端口 10131（前端）和 10130（后端）没有被占用。Windows 用户建议装 PowerShell 7，避免自带 PowerShell 5 的中文编码问题。

注意
如果你已经在 WSL 发行版里单独装过 Docker Engine，请先卸载或禁用它，否则会和 Docker Desktop 的 WSL 2 后端冲突，导致引擎连不上。

一个 AI 智能体

任意一款支持读取本地仓库文件并执行终端命令的智能体都可以，例如 codex、workbuddy 等。它的作用是把下面那句话翻译成实际的安装动作。

步骤 01

智能体一键部署

打开你的智能体，把下面这句话原样发过去。它会克隆仓库、读取 AGENTS.md、自动完成部署，最后把访问地址告诉你。 

复制# 发给智能体
克隆 https://github.com/Token-Spark/open-dreamina 到本地，按仓库 AGENTS.md 引导完成部署，最后告诉我访问地址。

智能体在后台实际会跑这些动作，你无需手动干预：

  1. 检查 docker version 与 docker compose version 是否可用；
  2. 检查 10131 / 10130 端口是否被占用；
  3. 运行部署脚本（deploy.sh 或 deploy.ps1），脚本会生成带随机 ENCRYPTION_KEY 的 .env；
  4. 执行 docker compose up -d --build 启动全部 5 个服务；
  5. 做健康检查，确认能访问后把地址交还给你。
部署完成后
应用地址：http://localhost:10131 ／ API 文档：http://localhost:10130/docs。数据目录是 ./data，里面包含 SQLite 数据库、生成资产与备份。

如果你更习惯自己动手，也可以不走智能体，直接在仓库根目录运行 bash deploy.sh（Linux/macOS）或 pwsh .\deploy.ps1（Windows）。

步骤 02

配置模型服务

打开应用后，进入「设置 → 服务管理」，在这里激活你要用的模型服务并填入对应的 API Key。一次可以激活多个服务，之后在创作界面里随时切换。填入的 Key 会用 .env 里的密钥加密后存储，不会明文落地。

目前可接入的模型服务大致分三类：

接入方式说明
API Key 直连Seedream、Seedance、GPT Image 2、Stability、通义万相、可灵等，填入厂商或中转网关的 Key 即可。
即梦 CLI复用本机即梦登录态生图生视频，无需 API Key，需先在服务管理里安装并登录 CLI。
Spark Hub 中转经中转站统一以异步任务模式调用 Seedream / Seedance，适合批量任务。
选哪个
想要图片就激活一个生图服务（如 Seedream 或 GPT Image 2），想要视频就激活 Seedance 或可灵。不确定时先激活一个，跑通流程再加其他服务。

用即梦 CLI 的话稍多一点步骤：在服务管理页面点「安装」，装完点「登录」并按提示完成授权。登录态保存在 ./data/dreamina-home，容器重建后也不会丢。

步骤 03

创建图片素材

模型激活后，回到创作界面新建一次图片对话。核心就两件事：选好生图模型，把画面描述写清楚。

文生图

选一个生图服务（例如 Seedream 5.0 或 GPT Image 2），在输入框里写下你想要的画面。一条好用的提示词通常包含主体、场景、风格、细节四个要素。比如：「一只橘猫趴在木质书桌上，午后阳光斜照，胶片摄影质感，浅景深」。点生成，等结果回来即可下载。

图生图（编辑）

把已有图片喂给模型，再用文字描述要做的修改——换背景、改色调、增删元素都可以。这适合在已有素材上做二次调整，而不是从零开始。

提示词小技巧
先写最重要的主体，再补充风格与氛围，最后加细节约束。一次只表达一个清晰意图，比堆砌一堆形容词更容易得到稳定结果。

每次生成的结果都会进入本地记录，可以随时回看、复用提示词或再次编辑，不需要重新下载。

步骤 04

创建视频素材

视频流程和图片类似，只是把生图服务换成 Seedance、可灵等视频模型。生成耗时更长，结果同样保存在本地记录里。

文生视频

直接用文字描述动态画面。视频提示词除了画面内容，最好再点明镜头运动和节奏，比如「镜头缓慢推进，水面泛起涟漪，宁静氛围」。运动描述越具体，画面越不容易静止或抖动。

图生视频

先用上一步生成的图片当起始帧，再用文字补充它该怎么动。这是把静态图片变成短视频片段最高效的方式，特别适合做封面动效或短视频素材。

节省时间的做法
先用便宜的生图模型快速产出满意的静态画面，再把它交给视频模型生成动态，比反复用文生视频试错更快也更省额度。

用智能体保持更新

项目发布新版本后，同样用一句话让智能体拉取最新代码并重建服务，无需你记命令。 

复制# 发给智能体
拉取 https://github.com/Token-Spark/open-dreamina 的最新代码（git pull），然后执行 docker compose up -d --build 重建镜像并重启服务，最后告诉我访问地址。

智能体会执行 git pull 拉取最新代码，再用 --build 重建镜像，确保前端静态资源和模型列表都是最新版本。你的数据始终留在 ./data，更新过程不会动它。

进阶用法

批量产出素材

同一个提示词配合多个模型，可以在服务管理里同时激活几家，逐个生成做横向对比；需要稳定产出大量片段时，走 Spark Hub 中转的异步任务模式更顺手，避免长任务占用交互界面。

数据备份

在「设置」里可以手动触发数据库备份，备份文件落在 ./data/backups，默认保留最近 3 份。换机器或升级前备份一次，是把风险降到最低的习惯。

让智能体帮你配模型

如果你不清楚某家模型的 Key 该填在哪，也可以直接问智能体，它能结合 AGENTS.md 与应用界面提示，一步步带你完成激活。涉及 API Key 时，只在应用的「服务管理」页面录入，不要把 Key 贴进对话或写进任何文件。

常见问题

智能体部署后打不开 localhost:10131 怎么办？

先让智能体跑 docker compose ps 确认 5 个服务都是 Up 状态，再看 docker compose logs backend 的启动错误。最常见原因是端口被占用或 .env 缺少 ENCRYPTION_KEY，重跑一次部署脚本即可。

生成的素材存在哪里，会不会丢？

全部存在本地 ./data 目录，包括 SQLite 数据库和生成资产。只要不手动删除这个目录，重建容器也不会丢数据。换机器前用「设置」里的备份功能导出一份即可。

没有 API Key 能用吗？

可以选即梦 CLI 方式，它复用本机即梦的登录态来生图生视频，不需要单独申请 API Key。在「服务管理 → 即梦 CLI」里安装并登录即可。

可以同时用多家模型吗？

可以。在服务管理里激活多个服务，创作时按需切换。多个服务之间互不影响，方便横向对比不同模型在同一提示词下的表现。

能不能不走智能体，自己部署？

完全可以。克隆仓库后，Linux/macOS 跑 bash deploy.sh，Windows 跑 pwsh .\deploy.ps1。脚本会自动完成环境检查、配置生成、构建与启动。智能体只是把这些步骤替你做了。

准备好开始创作了吗

把那句部署指令发给智能体，几分钟后就能在自己的浏览器里产出第一张素材。
