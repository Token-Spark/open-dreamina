Quickstart

三分钟完成部署

01

准备环境

安装 Docker 与 Docker Compose，确保端口 10130 / 10131 未被占用。

02

运行部署脚本

脚本自动完成环境检查、生成 .env、构建镜像、启动服务与健康检查。

03

开始创作

访问 localhost:10131，在「设置 → 服务管理」中激活模型服务即可使用。

# 克隆仓库
git clone https://github.com/Token-Spark/open-dreamina.git
cd open-dreamina

# Linux / macOS
bash deploy.sh

# Windows (PowerShell)
.\deploy.ps1
