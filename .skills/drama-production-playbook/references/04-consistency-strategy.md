# 04 五层锚点一致性策略

> 一致性不是生成出来的，是**锚定**出来的。五层锚点从风格到单集状态逐层收窄自由度：
> 前四层管「跨集不变」，第 5 层管「本集此刻」。
> 落库位置：`tools/assets_manifest.json` 的 `consistency_strategy` 字段（init 模板已内置骨架）。

## 第 1 层：风格锚点（全集统一）

所有生成（素材图 + 视频）尾部逐字拼接 style 四常量：

- `AESTHETIC`（美学基调）+ `MEDIUM`（媒介质感）→ 正向尾部
- `NEGATIVE`（负面词）→ 负面提示词
- `AUDIO`（音频约定）→ 提示词内的音频指令段

纪律：**逐字复用，禁止逐镜改写**。要换风格 = 改 manifest 一处 + 全量重生成预览镜验证。
`drama compile --with-style` 会自动追加（style 读 manifest，maps.py 的 STYLE 兜底）。

## 第 2 层：角色锚点（每角色一张 primary）

- 每角色**仅一张** primary 基准肖像，固定 seed（如 10001）——身份的唯一事实源
- 所有变体（半身像、三视图、多时期造型）以 primary 作 img2img 重绘
  （strength 0.45-0.75，脸部特征锁死，只改服装/时期）
- 视频生成**一律绑 `*_turnaround` 三视图**（正/侧/背全身，各角度一致性）；
  `_halfbody` 只作三视图的生成基准，**禁止作种子 / 参考 / 首帧**
- 同样禁止用单张剧照、上一版成片截帧、多图拼贴板做种子——单角度素材一转视角就漂移，
  这是「同一角色每镜都像换了个人」的主因
- 音色同样锚定：每角色一个 `anchor-voice.wav`（5 秒），TTS 选角记入 voice_manifest

多时期角色（如维纳斯 4 个时期）：每时期一套 `halfbody + turnaround` 配对，
按集段严格选用；基准脸不变，只变服装发型。
集段粒度（EP01-10）覆盖不到「单集内换装 / 染血 / 受伤」，那类走第 5 层。

## 第 3 层：场景锚点（primary + 室内布局/全景）

- 每场景**仅一张** primary 外观图（固定 seed）——作为风格 / 材质事实源
- 内景 / 变体（节庆态、夜晚态）以 primary 重绘派生
- **室内多角度场景必须额外建布局总览与全景锚点组**：一张 primary 只覆盖一个朝向，
  正反打会让两面墙对不上；各机位按朝向引用对应锚点，而不是都绑同一张 primary。
  触发条件、提示词骨架、朝向映射、登记与门禁见 `ai-video-director/references/20-indoor-layout-anchor.md`。
- 提示词中**减少环境文字描写**（让参考图说话）

## 第 4 层：关系锚点（多人 / 人物-场景共现，含名场面合成）

凡多人同镜、或同一「人物 + 场景」组合第 2 次及以后出现，必须先出一张已批准的
`rel_*` 关系关键帧，由同组合所有镜头复用（拆成单人正反打不免除）。
触发条件、命名登记、生成门禁、代码事实与 QC 见
`ai-video-director/references/19-relationship-keyframe.md` §2/§4/§6/§7/§8。

生成时职责分开：关系帧管「在哪」，角色 turnaround 管「长什么样」，
场景 primary 管「地方长什么样」，风格四常量照旧逐字拼接（见本文件第 1 层）。
关键爆点镜头的名场面合成（icon_epxx_*）是关系帧的一种特例。

## 第 5 层：集内状态锚点（单集锁定，生成时最后覆盖）

前四层锁的是「跨集不变」，锁不住「本集此刻」：同一集内换装、染血、受伤、卸妆，
以及本集独有的陈设（病床、输液架、药碗、灵位）。这些必须在**单集粒度**再锁一次，
否则会出现「第 3 镜换了外套、第 7 镜又换回来」「开头卧病在床、中段床不见了」。

- **人物**：本集妆造出一张三视图 `char_{角色}_ep{xx}_{造型}_turnaround`，
  视频与关键帧**只用它**，不用 primary、不用半身照、不用剧照
- **场景**：本集陈设出一张状态图 `scene_{场景}_ep{xx}_{状态}`，
  从 primary 派生，不重新文生图
- **道具**：随剧情改状态用 `prop_{道具}_{状态}`
- **提示词纪律**：妆造一经图片锁定，**只引用不描述**——提示词再写「白色睡裙、左袖咖啡渍」，
  会与参考图竞争，导致款式对但污渍换位，或整套换掉。场景陈设同理

触发条件、产物分工、生成顺序、门禁与 QC 见
`ai-video-director/references/21-episode-state-lock.md`。

## 一致性故障排查顺序

1. 检查引用环节：`drama assets EPxx` ——引用是否落到正确素材与 asset_id？
2. 检查锚点链：该资产是否从 primary 派生（而非 text2img 直出）？
3. 检查提示词：风格常量是否逐字拼接？是否混入改写的锚点？
4. 检查关系关键帧：多人 / 共现组合是否绑定已批准版本？站位是否漂移？（见 `ai-video-director/references/19-relationship-keyframe.md`）
5. 检查室内布局锚点：多角度场景是否有布局总览 + 按朝向的全景锚点？门窗/家具/光向是否一致？（见 `ai-video-director/references/20-indoor-layout-anchor.md`）
6. 检查集内状态锚点：本集妆造 / 陈设是否有专属锚点并已批准？换装点是否切了锚点？
   提示词里是否还在重复描述已被图片锁定的服饰？（见 `ai-video-director/references/21-episode-state-lock.md`）
7. 检查分镜本身：是否踩了 03 号文件的多人/运镜/时长红线？
8. 都没问题 → 才按生成随机性处理（重roll / 加参考 / 拆镜）。
