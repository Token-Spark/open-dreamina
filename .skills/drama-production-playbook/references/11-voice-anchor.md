# 11 角色音色锚点（anchor-voice）

> 契约 #23 的 owner（登记见 `10-contract-owners.md`）。
>
> **音色不是生成阶段的事，是角色资产的一部分。**
> 角色资产 = 基准肖像 + 三视图 + 音色锚点，三件套齐了才算这个角色做完。
> 少了 wav 就进入视频生成，等于让每一镜自己决定这个人什么声音——第 20 集才发现，
> 前面所有台词镜都要重出。

## 1 为什么必须在素材阶段定稿

- 音色锚点和脸部锚点同权重：每一条台词镜都要挂它，不是"补一张图"那种一次性的活。
- 前期不定 → 文字锚点只能写"低沉女声"，每镜各采样一次，全片就没有同一个人。
- 回补代价最大：该角色所有台词镜重出，重出会换脸、换表演，已验收的表演等于作废。
- 后期救不了：台词是生成期同期产出，禁后期 TTS 配音与口型合成（`03` 规则 6）。
  音色错了只能重出，不能拿配音盖过去。
- 成本结论：建库时一次性把所有角色的 wav 做完，后续集零新增——与三视图同批次做，
  这是奥林匹斯 93 项资产一次性建库的那条经验在声音上的同一件事。

## 2 产物规格（唯一口径；别处复述必须与本表一致）

| 项 | 值 |
|---|---|
| 文件名 | `{角色大写}_{时期/造型}_anchor-voice.wav`；基准版 `{角色}_PRIMARY_anchor-voice.wav` |
| 位置 | `素材库/01_characters/{角色小写}/`（与三视图同目录） |
| 时长 | **目标 5s，可接受 4–6s**（<3s 锁不住音色，>8s 没有额外收益） |
| 内容 | 一句连续台词（约 12–20 字 / 词），正常语速，情绪中性偏低 |
| 音质 | 纯人声：无 BGM / 垫乐、无混响与明显房间声、无环境噪、无音效、无第二个人声 |
| 格式 | wav / 单声道 / 44.1 kHz / 16 bit；峰值 ≤ −3 dBFS，不削波，全段响度均匀 |
| 语言 | = 剧集对白语言（须与该角色 `voice_manifest` 的 `languages` 一致） |

多造型角色默认**一角色一版音色**；确需变声的剧情（童年 / 老年 / 伪装 / 失声恢复）见 §7。

## 3 怎么产出（三条路径，按优先级选）

### A TTS 选角试听（首选，可批量、可复现）

1. 先读所选 TTS 通道的实时能力（`voice list` / `schema`），**不凭记忆编 flag 或音色名**
   ——与 `viral-remake/references/asset-generation.md` 同一条纪律。
2. 每个角色挑 2–4 个候选音色，用**同一句测试台词**各合成一条（同一句才可横评）。
3. 横评四项：性别与年龄感 / 音区与共鸣（明亮 ↔ 低沉） / 语速与咬字 / 口音与语言。
4. 定稿 → 导出 wav，按 §2 规格裁到 5s。**裁尾不裁头**，不要把咬字切掉，也不要用淡出掩盖截断。
5. 落盘到 §2 位置，登记 `voice_manifest.json`（§5）。

### B 真人 / 演员试录

同一句口播，近场麦、安静房间；转 44.1 kHz 单声道；授权与试听记录跟着项目走。

### C 已有音频截取（兜底）

只能从**干净人声**源截（录音、无乐素材）。**不得从带 BGM 的成片里直接截 5 秒**——
乐声一旦进锚点，每一条台词镜都会把它带回来（对应 `09` 的 E1）。

## 4 验收（5 项，逐条打勾；缺项按"角色未完成"处理）

1. 文件在 §2 路径，可解码（`ffprobe` 能读出时长与采样率）。
2. 时长落在 4–6s。
3. **纯人声**：完整听一遍——有没有乐、有没有混响、有没有底噪、有没有第二个人。
4. 与角色设定一致：性别 / 年龄感 / 语言，且与三视图的身份不冲突（粗嗓子配少女脸要重选）。
5. `voice_manifest.json` 已登记，`filename` 与磁盘一致，`group` 不重复。

机器能查的和查不了的：

- `opendreamina drama lint EPxx` → 台词镜「资产绑定」缺 `voice_*` 会出 warning（软检查，不改 `valid`；warnings 需逐条给处理结论）。
- `opendreamina drama assets EPxx` → `voice_*` 不走 `assets_manifest`，按
  `素材库/01_characters/{group}/*anchor-voice.wav` 找文件，缺文件会出现在 `missing_files`。

两者只能证明"绑了、文件在"，**时长、纯度、像不像必须人耳过**——这一项不要交给命令。

## 5 登记（`tools/voice_manifest.json`）

schema 与校验以代码为准：`drama/manifest/voice_manifest.py`。
必填 `group` / `filename` / `voice_type` / `voice_name`；选填 `casting_reason` / `languages`。

- `group` = 角色目录名（小写），必须与 `char_{角色}_*` 的角色段一致——资产与音色的自动配对靠它。
- `filename` = §2 的 wav 文件名，带扩展名。
- `voice_type` / `voice_name` = TTS 通道的音色 id 与展示名；真人录音写 `live` + 演员代号。
- `casting_reason` 写**为什么是它**，一句话即可（低音区 / 语速慢 / 带鼻音）。换角时这是唯一的对照依据。
- `group` 重复 = 校验 error（一角色一版音色）；`languages` 不含对白语言也是 error。

## 6 绑定与门禁（"避免重现"落在这一节）

**完成定义**：`{角色}_PRIMARY_anchor-portrait.png` + 首套 `*_turnaround.png` + `*_anchor-voice.wav`
三件套齐全，才是"角色资产已就绪"。缺任何一件 → 该角色**未完成**，不得提交素材审阅验收。

**门禁**：

- 缺 wav 的角色，其台词镜（含与之同镜的其他角色）生成任务标 `BLOCKED`，原因写「缺 anchor-voice」，
  回素材阶段补。**不许"先把画面跑出来，声音以后再说"**——声音没有"以后"。
- `shots.md` 台词镜在「资产绑定」写 `音色：voice_{角色}`；**无台词镜该槽写「—」、不传音频参考**
  （绑了会诱发模型自行出声，与「无对白」的负面词打架）。
- 生成装配时 `kind=audio` 的参考按 provider 分叉处理，见
  `production-orchestrator/references/10-generation-preflight.md` §2.2；
  wav 不得混进图片位（直连通道会把音频当图片编码，直接失败或污染参考集）。

## 7 变声例外（不鼓励，但必须有出口）

默认一角色一版。剧情确需变声：同目录再出一版
`{角色}_EPxx_{造型}_anchor-voice.wav`，在集内状态锁（`ai-video-director/references/21-episode-state-lock.md`）
登记切换点；`voice_manifest` 的 `filename` 指向**本集段在用的那一版**，切换时更新并留痕。

资产 ID 始终是 `voice_{角色}`——`ASSET_ID_RE` 只认这个前缀，不要发明 `voice_{角色}_ep07`
这类目录不存在的 ID（`drama assets` 会按 `素材库/01_characters/venus_ep07/` 找不到文件）。

## 8 "像不像"的 QC 口径

四项，任一**明显**偏离即判不一致：

| 维度 | 听什么 |
|---|---|
| 音高区间 | 整体偏高还是偏低，是否有明显的升降调漂移 |
| 共鸣位置 | 胸声 ↔ 头声、明亮 ↔ 暗沉 |
| 语速与断句 | 字/秒，句尾是否拖或赶 |
| 口音与咬字 | 地域腔、咬字松紧、气声比例、年龄感 |

判定顺序（按成本从低到高，别一上来就重 roll）：

1. 该镜绑的 `voice_*` 是不是正确的角色（最常见：绑错 ID）。
2. 这一版 wav 是不是当前集段该用的那一版（换过段没切）。
3. prompt 是否写了与锚点矛盾的语气 / 年龄 / 口音（文字与音频打架，模型各取一半）。
4. 以上都对仍不像 → 才重出；不要靠"多传一个 wav"或后期变声去救
   （`production-orchestrator/references/10-generation-preflight.md` §2.2 有反例）。

## 9 高频失败对照

| 症状 | 根因 | 修法 |
|---|---|---|
| 到第 N 集才发现某角色声音和前面不一样 | 素材阶段没做 wav，各镜靠文字自由采样 | 定稿 wav 并登记，补绑 `voice_*`，该角色台词镜整批重出（代价最大的一类返工） |
| 声音对了但每镜差一点，音高在飘 | 只绑了图片没绑音色，或 wav 太短 / 带噪 | 换 4–6s 干净版；台词镜补 `音色：voice_{角色}` |
| A 的台词用了 B 的音色 | `voice_manifest` 的 group 填错，或 shots 绑错 ID | 改绑定；跑 manifest 校验查重复 group |
| 传了 wav 直接报错 / 参考集被污染 | 直连 `seedance-2-x` 不区分类型，音频被当图片编码 | 按 `10-generation-preflight.md` §2.2 分叉：该通道剥离音频，只走 sparkhub 的 `audio_urls` |
| 台词镜没出声，或像旁白朗读 | wav 本身是无情绪朗读，prompt 也没写语气 | 锚点换成带语气的一版；同时补 prompt 的语气 / 语速 |
