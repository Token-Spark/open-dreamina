# 03 视频生成实战经验（Seedance）

> 来自生产实测与用户调研的 5 条核心经验 + 奥林匹斯补充规则。
> 进入生成环节前必读；写分镜时就要按这些约束设计，而不是生成失败后再补救。

## 五条核心经验（用户调研原文沉淀）

### 1. 多人镜头是最高风险项
多人同镜极易出错（面部崩坏、身份混淆、动作穿插失控）。
**应避免或减少多人镜头**；剧情必须多人时：
- 提供空间参考素材图片（多人站位关系图）
- 或拆成正反打单人镜头（AI 最擅长：单人正反打 + 台词推进）

### 2. 长内容单人物一致性靠素材引用纪律
相邻镜头不一致、相邻剧集不一致是长篇内容的头号问题。对策：
- 确保**引用素材环节正确**：人物绑三视图（turnaround），音色绑 anchor-voice
- 多形象（多时期/多造型）必须**完整充足地提供引用素材并合理编号区分**
  （如 `VENUS_EP01-10_white-gown` vs `VENUS_EP21-30_rosegold-queen`），避免错引

### 3. 单镜时长控制
单个镜头**以 6 秒以内为宜**；例外：多人互动物理接触戏（对打/搀扶）、
较长台词——这类镜头需要一致性与连贯性，可放宽，但要接受更高重生成率。

### 4. 人物参考图要经剧集风格化处理
通用真人参考图直接用会产生「素材感」与 AI 感。参考图必须在素材生成环节
就按剧集美术基调做风格化（画风常量注入 img2img 重绘），而不是靠视频生成兜底。
（例：奥林匹斯的 90 年代电视剧质感在人物肖像阶段就锁定。）

### 5. 素材目录分层管理，重新生成可覆盖
素材、分镜内容、分镜剧本**分别管理**（素材库 / video_renders / shots.md）：
- 分镜内容变更 → 重新生成的视频直接覆盖 `video_renders/{镜号}*/`，不与素材冲突
- 素材更新 → 只动素材库，分镜与剧本不动
- 废弃版本进 `_superseded_*` 目录，可追溯可回滚

## 奥林匹斯补充规则（分镜设计约束）

1. **杜绝复杂运镜**：单人物镜头 + 台词动作推进剧情；减少长镜头调度与多人互动。
2. **心理/说话画面**：人物占画面 75% 以上，减少背景设定与曝光。
3. **引用环境图时减少环境文字描写**：提示词里环境描述与参考图冲突时模型会
   自行发挥——让图说话，文字只做锚定。
4. **禁止夸张特效**：光柱、火花、3D 渲染、建筑地面形变一律负面词伺候；
   用高度写实画面表现超自然。
5. **首尾帧模式慎用**：优先全能参考（reference）模式；首尾帧易画面不协调。
6. **音频纪律**：生成环节只剔除 BGM，**禁止整体静音**（人声 + 动作音效 +
   环境音必须保留，qc 会查音轨与电平）；BGM 后期统一铺设。
7. **参数基线**：Seedance 720p / 9:16 / 全能参考 / 轮询上限按平台队列取宽。

## 生成执行入口

单镜验证：`opendreamina image2video --provider sparkhub-seedance --reference <三视图> --reference <场景图> --prompt "<编译后提示词>" --aspect-ratio 9:16 --auto-wait`

批量生成：读 `tools/episode_specs/EPxx.json` 逐镜执行（refs → --reference，
prompt + style 常量 → --prompt），产物按 `{镜号}_seedance20/` 落 video_renders；
断点恢复 = 跳过已有成片的镜号。
