# 09 高频错误复盘清单（实战踩坑 → 先查 → 对策）

> 本文件汇总本仓实战返工中反复出现的错误形态，按故障域分组。每条给「现象 / 根因 / 先查 / 对策 / 规范落点」。
> 原理见 `03-seedance-best-practices.md`、`04-consistency-strategy.md`、`production-orchestrator/references/10-generation-preflight.md`；
> 本文件只做**症状索引与快速定位**，不重复展开原理。提交前对照本清单逐项过一遍。

## 返工 Top 榜（代价最高，优先拦）

1. 跨分组背景漂移（同一场后一组漏挂场景图，串到别的空间）。
2. 手持道具变色 / 变形（道具参考图没进参考列表，只靠文字描述）。
3. 生成期烧录台词字幕 / 屏幕文字。
4. 多角色 / 多空间塞进同一连拍组，串脸、串空间、串音色。
5. 夹带 BGM / 垫乐，或反过来整条音轨被静音。

## A. 画面文字类

### A1 生成期烧录台词字幕 / 标题卡 / 水印

| 项 | 内容 |
|---|---|
| 现象 | 人物台词以白色硬字幕出现在画面底部/顶部/四角；出现标题卡、字幕条、屏显标题、文字水印、logo、签名、边框；偶有把台词里的字写错（「她」→「他」）。 |
| 根因 | 生成模型自行把台词上屏；提示词只在句尾零散写 "no subtitles"，约束力不足。 |
| 先查 | 台词镜块尾是否有「台词仅以人声播出、不上屏」；全局是否有屏幕文字禁令（中英）；负面词是否点名 subtitles / captions / on-screen text / watermark / logo / signature / border。 |
| 对策 | ① 全局加屏幕字幕禁令段；② 每条台词/旁白镜块尾声明「仅人声播出，不要把对应文字打上屏幕」；③ 负面词补字幕/标题卡/屏幕文字/水印/logo/签名/边框中英词；④ 后期才烧录字幕，生成期一律无文字。 |
| 落点 | `03` 规则 6；`04` 第 1 层风格负面；本仓生成脚本 `SCREEN` / `NEG` 段。 |

### A2 信纸 / 纸面残字、乱码、错字

| 项 | 内容 |
|---|---|
| 现象 | 本应空白的信纸/信封/册页/招牌/站牌上出现不可辨识笔画、乱码、缺字；或要求可读的手写信逐字错误。 |
| 根因 | 未按纸面文字纪律分镜型标注；模型自由补字。 |
| 先查 | 该镜是否标 `text_ok`（要求可读）；其余纸面是否在 BLANK 空白表面纪律内。 |
| 对策 | 不需要可读的纸面一律写「完全空白表面，无文字/数字/笔画/墨迹」；要求可读的信纸单独 `text_ok` 并绑信纸字形参考，声明逐字正确、不乱码缺字。残留少量不可辨识字迹列入后期遮罩清单，不在生成层反复抽卡。 |
| 落点 | 本仓 `BLANK` / `BLANK_TXT` 常量；`03` 规则 4 负面词。 |

## B. 空间背景类

### B1 跨分组背景漂移（同一场拆多个连拍组）

| 项 | 内容 |
|---|---|
| 现象 | 相邻两组（或组内前后镜）背景墙面、门窗、陈设、光向、色调对不上；后一组串到户外小巷、别的房间或别的空间。 |
| 根因 | 后一组 assets 漏挂场景图；分组 `loc` 错标到别的场景；模型缺空间锚点自由发挥。 |
| 先查 | 同一场的**每个组**是否都挂了同一张 scene primary；分组 loc 与分镜实际空间是否一致；相邻组衔接帧（前组尾镜/后组首镜）是否并排核对过。 |
| 对策 | 每组挂同一 scene primary；loc 与实际空间一致；空间锚点段声明跨组背景结构/光向/色温一致、不漂移；QC 并排核对衔接帧，对不上先查挂参考与 loc，不直接重 roll。 |
| 落点 | `04` §3.1；`10` §2.3/§2.4；经验 `background-continuity-and-prop-color-lock`。 |

### B2 场景文字描述与参考图冲突

| 项 | 内容 |
|---|---|
| 现象 | 提示词写了参考图里没有的陈设（某架藤蔓、某件家具），模型按文字生成出图里不存在的背景；或描述颜色/结构与图不符。 |
| 根因 | 环境文字描写过多，与参考图竞争；先写了文字、后核对图不一致。 |
| 先查 | 场景段每个陈设词能否在 primary/状态图里指到实物；文字与图有无冲突。 |
| 对策 | 让参考图说话，文字只做锚定；图里没有的元素不写进文字。要改背景陈设 = 先从 primary 派生状态图，再改文字。 |
| 落点 | `03` 规则 3；`04` 第 3 层。 |

### B3 室内反打后换墙、门窗移位

| 项 | 内容 |
|---|---|
| 现象 | 正反打后两面墙对不上，门窗位置变了。 |
| 根因 | 室内跨机位只引了一张 primary，覆盖不到另一侧朝向。 |
| 对策 | 室内多角度补 `loc_*` 布局总览/全景锚点，按朝向分别引用。 |
| 落点 | `04` 第 3 层；`20-indoor-layout-anchor.md`。 |

## C. 道具类

### C1 道具变色 / 变形 / 被替换成别的物件

| 项 | 内容 |
|---|---|
| 现象 | 同一道具相邻镜颜色乱变（车模米黄→红绿白→白黄）、形制走样（公交车变小汽车）、换成另一物件。 |
| 根因 | ① 道具 v03 参考图没进参考列表（装配只收角色/场景），只靠文字描述；② 无配色/形制文字锚点；③ 参考装配按序号截断，第 4 个以后的道具被静默丢弃。 |
| 先查 | 道具图是否真的出现在该组 refs 里；PROP 锚点是否写死配色/形制/材质；refs 有无被 `[:n]` 截断。 |
| 对策 | 道具状态版参考图与角色三视图、场景 primary 同列入参考；PROP 锚点写死关键辨识项（配色、形制、材质、磨损）；声明全组不变色/不变形/不替换；取消关键道具的序号截断；同集同道具只引一个版本。 |
| 落点 | `04` 第 4.5 层；`10` §2.1 道具行、§2.5；经验 `background-continuity-and-prop-color-lock`。 |

### C2 道具状态前后不一（信撕了又完好、布脏了又干净）

| 项 | 内容 |
|---|---|
| 现象 | 道具在剧情中状态应变化，画面里却一会儿新一会儿旧。 |
| 根因 | 未按剧情切 `prop_*_{状态}` 版本。 |
| 对策 | 变化发生的那一镜起切对应状态版（open / worn / flat…），跨状态镜不同组。 |
| 落点 | `04` 第 5 层；`10` §2.5。 |

## D. 角色与声音类

### D1 串脸 / 串空间：多人多空间塞进同一连拍组

| 项 | 内容 |
|---|---|
| 现象 | 本该在别处的角色出现在本组画面；两人被塞进同一段；某镜串成陌生脸/陌生空间。 |
| 根因 | 一组跨多个空间、多个角色，组级参考各取一半；靠负面词压不住。 |
| 先查 | 该组是否跨场跨时、角色数是否超组内安全量；参考是否覆盖到每个出场角色与空间。 |
| 对策 | 按空间与「每段只留一个角色」拆组；跨空间/多角色不硬合；拆组后每组参考自足。 |
| 落点 | `03` 规则 1/9；`10` §3；经验 `take-group-identity-swap-by-splitting`。 |

### D2 音色串角色 / 变声 / 变年轻

| 项 | 内容 |
|---|---|
| 现象 | 某角色台词配成另一人的音色；老年男声变年轻、变声；同组几条声线互相穿插。 |
| 根因 | 多声线同组穿插互相干扰；**素材阶段就没产出 anchor-voice.wav / 没绑音色锚点**（最高频，且到中后段才暴露）；角色文字锚点缺声线描述。 |
| 先查 | `@voice_id` 是否绑到正确角色；`drama assets` 的 `missing_files` 里有没有音色；wav 是否为当前集段该用的那版（规格与纯度见 `11` §2/§4）；角色锚点是否写了声线（音色/语速/年龄感）；该组是否多角色多声线。 |
| 对策 | 素材阶段补定稿 wav 并登记 `voice_manifest`（见 `11`），再绑正确音色锚点；CHAR 锚点补声线描述并声明全片同一音色、不变声；多声线高危组按 D1 拆组；出问题先重绑 ID 与锚点，不靠后期 TTS 补。**回补意味着该角色台词镜整批重出**——所以门禁要放在建库时。 |
| 落点 | `11`（契约 #23 owner：规格 / 产出 / 门禁）；`04` 第 2 层；`10` §2.5；`03` 规则 6。 |

## E. 音轨类

### E1 夹带 BGM / 垫乐 / 旋律

| 项 | 内容 |
|---|---|
| 现象 | 成片出现背景音乐、和弦、鼓点、乐器垫乐、氛围铺底。 |
| 根因 | 只在句尾写零散 "no music"，约束力不足；未双通道压制。 |
| 先查 | 正向 AUDIO 段是否前置声明禁乐并实填环境音/触发音；负面词是否点名乐种（score / strings / piano / pad / beat / melody…）。 |
| 对策 | 双通道：正向前置禁乐＋实填环境/触发音，负向点名乐种；生成环节禁任何 BGM，原创配乐只在后期统一铺。 |
| 落点 | `03` 规则 6；`prompt-optimizer/02` §4.5；经验 `seedance-cli-no-audio-switch-music-suppression`。 |

### E2 空轨 / 整体静音（与 E1 对称的另一头）

| 项 | 内容 |
|---|---|
| 现象 | 无台词镜整条音轨为空；或为消乐把整段音轨静音。 |
| 根因 | 把「禁 BGM」误当成「静音」；`generate_audio` 只能整条开关，不能选择性去乐。 |
| 对策 | 台词镜保留人声；其余镜保留基础环境音＋动作触发音（foley），近静音＋呼吸/动作级底噪即可；QC 查音轨存在性与电平，空轨不通过。 |
| 落点 | `03` 规则 6；`10` §4。 |

### E3 台词没出声 / 吞字 / 口型对不上

| 项 | 内容 |
|---|---|
| 现象 | 台词镜没人声；台词咬字不全、被切点切断；口型与声音不符。 |
| 先查 | 台词是否逐字写进 prompt（说话人/语气/语速）；镜时长是否够念完（字数 ÷ 3–3.5 字/秒 ＋ 起势 0.5s）；切点是否压在尾音上。 |
| 对策 | 台词逐字进 prompt 同期出声；按字数反推镜时长，超语速镜先补时长再考虑重出；没出声/错字/口型不对 → 改 prompt 或换模型重出，禁止后期 TTS＋口型合成。区分「吞字（需重出）」与「尾音被切（后期可救）」。 |
| 落点 | `03` 规则 6；经验 `storyboard-runtime-budget-from-spoken-chars`。 |

## F. 装配与参数类

### F1 参考被序号截断 / 视图缺口导致静默丢参考

| 项 | 内容 |
|---|---|
| 现象 | 某角色/场景/道具没出现在画面里，或自由发挥；生成不报错，只是参考没挂上。 |
| 根因 | 装配代码按 `[:n]` 截断参考列表；某视图版本文件不存在又回退失败；资产版本收敛后漏掉旧版独有的图。 |
| 先查 | 跑一遍 refs 覆盖核对：组内每个 `char_/scene_/prop_` 资产是否都能在 refs 里命中；有没有文件不存在被跳过。 |
| 对策 | 关键角色/场景/道具不做序号截断（或上限留足）；缺图先补资产再生成；引用解析不出来就不提交。 |
| 落点 | `10` §2.6；经验 `asset-version-prune-and-reference-coverage-audit`。 |

### F2 时长 / 参考模式硬参数漏传

| 项 | 内容 |
|---|---|
| 现象 | 多镜组只出了第一镜（落默认 5s）；多图参考只剩第一张当首帧，其余参考全丢。 |
| 根因 | `--duration` 未显式给；`--frame-mode` 未显式传 `reference`（缺省按 provider 分叉，直连落回首帧）。 |
| 对策 | 单镜 `duration`=该镜时长，连拍组=组内各镜时长之和，必须显式传；`frame-mode` 显式 `reference`；`first` 须在 sidecar 写首帧理由。 |
| 落点 | `03` 规则 5/7；`04-generation.md` §4；`10` §4。 |

### F3 独立负面词被 provider 丢弃

| 项 | 内容 |
|---|---|
| 现象 | 命令行/参数里传了 `negative_prompt`，但上游没生效。 |
| 根因 | 部分中转 provider 的 payload 构造未把独立负面词写入上游字段；该通道不走独立负面字段。 |
| 先查 | 对应 provider `_build_create_payload` 是否真的把 negative_prompt 写进 payload。 |
| 对策 | 以「负面约束留在正向 prompt 文本内」为准；独立负面参数可同时传作兜底，但不能只靠它。换通道前先核实该通道负面词字段是否生效。 |
| 落点 | 本仓 provider 代码事实；`prompt-optimizer/02` §4。 |

### F4 本地参考图未上传审核

| 项 | 内容 |
|---|---|
| 现象 | 图片参考直接报错或被忽略。 |
| 对策 | sparkhub 通道本地图片须先上传并审核通过再引用；音频锚点转公网 URL，免审。 |
| 落点 | 经验 `sparkhub-seedance-reference-asset-audit`；`10` §2.2。 |

### F5 后端启动工作目录契约（运维坑）

| 项 | 内容 |
|---|---|
| 现象 | 本地起后端报 `encryption_key missing` / 10130 拒连。 |
| 根因 | celery worker 在错误目录启动，读不到根 `.env` 的 ENCRYPTION_KEY。 |
| 对策 | redis / uvicorn / celery 必须在仓库根目录起；`health` 检查 worker=ok 再提交。 |
| 落点 | 经验 `local-backend-restart-cwd-contract`。 |
