# 02 六步流水线与三级剧本体系

## 六步流水线（质检贯穿全程）

```
选题 → 剧本 → 素材 → BGM → 视频 → 海报/成片
        ↑人工确认    ↑人工验收    ↑人工检查        ↑人工检查
              ↑机器检查(lint)
```

工程化四板斧（奥林匹斯验证）：

1. **拆解标准**：每集 90s / 18 镜 / 15 行模板——统一到可机器解析。
2. **规范约束**：无 BGM / 无字幕 / 无 Logo / 无夸张特效；竖屏三段法构图。
3. **自动化流水线**：lint → compile → spec → 生成 → qc 全链命令化。
4. **质检闭环**：抽帧 qc、引用完整性、台词校验、断点恢复。

## 三级剧本体系（逐级确认）

| 层级 | 文件 | 内容 | 检查 |
|---|---|---|---|
| 1 剧本大纲 | `剧本大纲.md` | 八幕结构、分集骨架（每幕 5 集左右，各幕有情绪基调） | 人工 |
| 2 分集剧本 | `分集剧本/分集剧本_EPxx-xx.md` | 每集 4-5 个 SCENE，含台词、动作、运镜、13 要素 | 人工 |
| 3 分镜脚本 | `分镜脚本/EPxx/shots.md` | 18 镜 × 15 行模板，秒级拆解 | 机器（drama lint） |

分集剧本 SCENE 的 13 要素（从奥林匹斯规范提炼）：镜头功能 / 人物 / 场景描述 /
秒级动作拆解 / 台词同步 / 人物关系位置 / 空间关系位置 / 光感 / 色调 / 构图 /
细节 / 音效设计（三层）/ 第一视角设计。

分镜脚本从分集剧本机械拆出：**台词逐字引用不可改写**；一个镜头只解决一个
主要视觉任务；复杂动作拆镜头，用剪辑制造复杂度。

## 每集制作的命令路径

```bash
EP=EP01
opendreamina drama lint $EP --project .            # ① 分镜格式（errors=0 才继续）
opendreamina drama assets $EP --project .          # ② 资产缺口清单（指导素材生产）
# ③ 素材生产：generate_assets → 素材审阅中心人工验收
opendreamina drama compile $EP --project .         # ④ 编译英文提示词
opendreamina drama spec $EP --project . --write    # ⑤ 分集执行规格落盘
# ⑥ 批量生成 → video_renders/
opendreamina drama qc $EP --project .              # ⑦ 技术验收
# ⑧ shot-reviewer 初审 → 审片中心人工终审 → 返修迭代
```

## 节奏参照（奥林匹斯实测）

- 大纲 + 40 集分集剧本：先行完成（人工投入最大的环节）
- 素材生产：93 项资产一次性建库，之后各集零新增（一致性最好的投入）
- 分镜：每集 18 镜，写作 + lint 修错约 1-2 小时/集
- 生成 + 质检：批量并发，断点恢复；返修按镜号精确重生成
- 成片：转码 → concat → 响度匹配 → BGM 铺设，全部脚本化
