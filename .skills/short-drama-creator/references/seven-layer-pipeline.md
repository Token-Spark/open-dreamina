# 从创意到成片：七层创作 Pipeline 与剧作交接契约

> 对应 SKILL.md 索引中的 `references/seven-layer-pipeline.md`。
> 新开项目、判断「当前问题出在哪一层」、以及向分镜 / 制片交接时加载。

## 1. 为什么要分层

传统电影剧本可以交给导演、摄影师、美术师、演员共同进行**二次创作**；
AIGC 制作没有现场——在生成之前，场景、人物动作、画面构图和摄影机运动
就必须描述清楚。

> AI 影视创作者需要把故事进一步转化为**机器能够执行、验证和复现的视觉制作指令**。

第 4–5 层（场景拆解 + 分镜设计）就是这个转化的分水岭：
`short-drama-creator` 负责第 1–3 层，`ai-video-director` 负责第 4–5 层。

## 2. 七层定义

| 层 | 名称 | 输入 → 输出 | 门禁 | 负责技能 |
|---:|---|---|---|---|
| 1 | 创意开发 | 想法 → 一句话创意、主题、类型、受众、故事核心问题 | Premise 成立（含选择 / 代价 / 不可逆后果） | `short-drama-creator` |
| 2 | 故事设计 | 创意 → 世界观、人物圣经、人物关系、人物弧光、故事结构 | 人物网含镜像对手 + 代价承担者；结构五节点齐全 | 同上 |
| 3 | 剧本写作 | 故事 → 梗概、分场大纲、场景设计、完整剧本、对白 | 标准剧本格式；每场价值极性有变化；D1→D4 通过 | 同上 |
| 4 | 场景拆解 | 剧本 → 每场目标、冲突、人物动作、情绪变化、道具、连续性 | `Scene Start ≠ Scene End`；价值起止极性已标注 | `short-drama-creator` → `ai-video-director` |
| 5 | 分镜设计 | 场景 → 每镜景别、机位、构图、人物调度、摄影机运动、画面内容 | 12 字段齐全 + 四问可解释 + 机位图 / 轴线 + 切点依据 | `ai-video-director` |
| 6 | AI 视觉生产 | 分镜 → 一致性资产、关键帧、视频、声音配乐 | 空间锚点门禁（见 `ai-video-director/references/19-relationship-keyframe.md` §6 / `20-indoor-layout-anchor.md` §7）；Keyframe 门禁；资产 ID 100% 落位；`drama lint` errors = 0 | `production-orchestrator` |
| 7 | 剪辑与审片 | 素材 → 节奏、连续性、表演、声音、情绪曲线、叙事完整性 | `drama qc` + `shot-reviewer` 初审 + 人工终审 | `shot-reviewer` + 审阅中心 |

## 3. 剧作层向分镜层的交接契约（本技能的责任）

第 3 层交付的不是「写完的剧本」就完事，必须是**第 4 层能直接拆的东西**：

| 交付项 | 下游怎么用 |
|---|---|
| Premise / Theme Statement / 价值对 | 决定分镜的价值转折落点与色彩弧线 |
| 弧光卡 + 人物网对照表 | 决定视点归属、谁占画内 / 画外、距离与高度关系 |
| 结构五节点 + 场景解剖表 | 决定场景的建立-维持-打破、机位图与轴线 |
| 标准剧本 + 潜台词注 | 决定对白镜的正反打、反应镜头、切点时机 |
| 视觉设计重点（文学→视听转译） | 决定视觉母题、意象系统、匹配剪辑依据 |

硬规则：

1. **上游问题在上游修复**。生成阶段修不了剧本层的问题；重新抽卡只会放大成本。
2. 场景没写到「目标 / 阻力 / Beat / 价值转折」，不许进分镜——导演收到剧情梗概只能凭感觉编机位。
3. 心理活动必须外化成可拍动作或物件；「他感到后悔」不是可交接内容。
4. 创作期标准剧本与交接期 SCENE 清单是两套产物（见 `story-anatomy.md` §6），不互相覆盖。

## 4. 典型失败与回溯层级

| 症状 | 真正出问题的层 | 不要误判成 |
|---|---|---|
| 爽完即空、结局无力 | 1（Premise 缺失） | 节奏不够快 |
| 配角工具人、动机靠巧合 | 2（人物网） | 演员 / 生成没演好 |
| 场景无变化、对白宣讲主题 | 3（价值标注） | 台词不够漂亮 |
| 分镜拿到的是剧情梗概 | 4（场景拆解） | 导演能力不足 |
| 空间崩塌、视点混乱、切点无理由 | 5（分镜设计） | 模型不稳定 |
| 角色换脸、场景跳变 | 6（资产未锁） | 提示词写得不好 |
| 单镜都好看、连起来不成戏 | 5（切点）或 7（剪辑） | 素材质量 |

## 5. 与传统流程的差别

| | 传统影视 | AIGC 影视 | 本仓库对策 |
|---|---|---|---|
| 剧本 | 文学剧本，允许现场二度创作 | 必须写到可执行 | 层 4–5 字段化 |
| 分镜 | 沟通参考 | **生成指令的直接来源** | `ai-video-director/references/17-storyboard-vs-shotlist-dual-output.md` |
| 空间 | 现场走位解决 | 生成前写死 | 机位图与轴线（`13`） |
| 一致性 | 同一演员 / 场景天然一致 | 每次生成都可能漂移 | 层 6 资产 ID 锁定 |

> `drama-production-playbook` 的实战流水线是这七层在 Open Dreamina 工具链里的具体实现；
> 本文件是**创作决策链**，不是资产生产链（后者见 `ai-video-director/references/09-pipeline-and-qc.md`）。
