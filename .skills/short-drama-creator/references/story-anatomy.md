# 结构解剖、价值变化与标准剧本格式

> 对应 SKILL.md 索引中的 `references/story-anatomy.md`。
> STEP 6–9 前加载。把现有的「五点 Season Arc / 六段式单集 / 八幕模板」
> 补上因果节点与场景级的解剖方法，并定义标准剧本交付格式。

## 1. 一套序列，三种体裁共用

经典设计（大情节）的因果序列：

```text
激励事件 → 进展纠葛 → 危机（真正两难）→ 高潮（最大不可逆价值转折）→ 结局
```

| 节点 | 定义 | 常见误判 |
|---|---|---|
| 激励事件 Inciting Incident | 彻底打破主人公生活平衡、迫使他产生新欲望的**单一事件** | 不等于 HOOK；HOOK 是开场抓人技巧，激励事件是故事因果的起点 |
| 进展纠葛 | 欲望推进中阻力逐级升级，且每次都关闭一条退路 | 不是「事件变多」，是「代价变大」 |
| 危机 Crisis | 主角面对两难、且**两个选项都有不可逆代价**的最后抉择点 | 不是最危险的一刻，是最难选的一刻 |
| 高潮 Climax | 由**主角主动选择**达成的最大价值转折，此后不可回头 | 不是打斗最激烈处，也不是反派被揭穿处 |
| 结局 | 高潮之后价值落在哪一端、谁付了什么代价 | 不是交代后续，是主题判决 |

三级高潮：幕高潮 / 集高潮 / 全剧高潮，逐级放大且**必须由同一对价值串联**
（取值表见 `premise-theme.md` §5）。

映射（不替换，只补节点定义）：

- `workflow.md` STEP 6 五点 Season Arc → 在「起点→中点→真相→崩塌→最终选择」上标注上述五节点。
- `series-design.md` §2 的 5 集小 Arc → 每个小 Arc 至少一次进展纠葛 + 一次局部危机。
- `drama-context.md` 八幕模板 → 「终局」必须含高潮选择 + 道德后果，不能只收网。
- Setup / Payoff 写法仍按 `episode-structure.md` §6，本文件不重复。

## 2. 价值标注法（麦基式场景解剖）

每个场景写成一条**价值变化式**：

```text
场景价值：[二元价值] 由 [起始极性] → [结束极性]，转折点是 [某个动作 / 信息 / 选择]
```

例：`真相/忠诚：忠诚(+) → 真相(+)`，转折点是「她把兄长的名字念了出来」。

规则：

1. 先标价值对，再写场景；不要先写事件再补意义。
2. **场景起止极性相同 = 无变化 = 删除或合并**（与 `ai-video-director/references/02-breakdown.md`
   的 `Scene Start ≠ Scene End` 同构，一个在编剧层、一个在导演层）。
3. 极性翻转必须发生在**场景内部**，靠一个动作或一句台词完成，不能靠转场到下场戏。
4. 极性的蓄积与翻转就是爽感：「压抑 → 释放」= 价值负极累积到正极的一次大幅翻转。
   `hit-methodology.md` §2.4 与 `narrative-craft.md` §5 的直觉判定，在这里被操作化。

## 3. Beat、Gap 与「一场戏 = 微缩故事」

| 概念 | 定义 | 与现有概念区分 |
|---|---|---|
| Beat 节拍 | 动作 / 反应的最小单位：谁做了什么 → 对方如何反应 | **不是** `narrative-craft.md` §8 的「信息密度 / 每 10–20 秒一次变化」；那是节奏，这是结构单位 |
| Gap 裂口 | 人物期望的结果与实际结果之间的落差 | 与 `narrative-craft.md` §3 反转（Unexpected + Inevitable）互补：Gap 发生在场景内，反转发生在集级 |
| 场景内转折 | 场景价值极性翻转的那一拍 | 现有流程只在集级设 Escalation / Reveal |

一场戏的最小解剖：

```text
SCENE 标题 / 价值对 / 起极性
  人物目标 → 阻力 →
  Beat 1 动作 / 反应 → Beat 2 … →
  Gap：期望 __ / 实际 __ →
  转折点：__ → 终极性 __
```

## 4. 故事三角与适用边界

| 形态 | 特征 | 何时启用 |
|---|---|---|
| 大情节 / 经典设计 | 因果闭合、主动主角、明确高潮 | **默认**：竖屏短剧、商业长片、类型片 |
| 小情节 / 最小主义 | 内在冲突、开放结局、日常尺度 | 用户明确要作者短片 / 横屏文艺片 |
| 反情节 | 巧合、断裂、非线性 | 实验创作；**禁止**直接套进留存导向的短剧 |

原则：**结构从人物的欲望、选择、冲突与代价中长出来**，
不是先选一个结构公式再把人物塞进去。先完成 `premise-theme.md` 与 `character-arc.md`，
再回看序列是否自然吻合；不吻合时改人物，不要硬掰节拍。

## 5. 标准剧本格式（创作期交付物）

剧作评审用标准剧本，不用 SCENE 清单：

```text
INT. 老宅书房 — 夜

她把族谱摊在桌上，指尖停在那个被划掉的名字上。
门外，脚步声停住。

                兄长
          你真的要把我写进去？

她没有抬头，把墨重新研开。

                她
          我十年前就该写。

                                CUT TO:
```

格式要点：

- Slugline：`INT./EXT. + 地点 + 日/夜`，一场一行；地点换了就换场。
- 动作行：只写**可拍摄**的现在时动作；心理活动必须外化（`narrative-craft.md` §7）。
- 对白块：角色名独立一行，台词在下一行；括号提示（parenthetical）只用于动作/语气，且尽量少。
- 转场（`CUT TO:` 等）只在必要时写，不逐场堆。
- 潜台词可在**对白块旁加一行 `〔潜台词：…〕` 作为创作注**，创作期保留，交接生成前必须删除。

## 6. 两套交付物，不要混

| | 创作期：标准剧本 | 交接期：SCENE 清单 |
|---|---|---|
| 用途 | 剧作评审、改稿工作坊 | AIGC 管线生成约束 |
| 规范 | 本文件 §5 | `drama-context.md`（台词冻结、9:16、单镜 ≤6s、少写复杂运镜） |
| 谁消费 | 人 / 编剧 Agent | `ai-video-director` → `drama lint` |

**关键**：`drama-context.md` 建议「少写复杂运镜」是**生成约束**，
不是剧作标准；创作期仍须按 §5 写出完整动作与场面意图。
两套产物在 STEP 9 之后各存一份，不得互相覆盖。

## 7. 输出格式（STEP 6 / 8 / 9 追加项）

```text
【结构序列】激励事件 / 进展纠葛 / 危机 / 高潮 / 结局 + 各自所在集号
【场景解剖表】场号 | 价值对 | 起→止极性 | 目标 | 阻力 | Beat 序列 | Gap | 转折点
【标准剧本】Slugline / Action / Dialogue（含潜台词注）
```
