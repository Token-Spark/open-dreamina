# 人物弧光与人物网

> 对应 SKILL.md 索引中的 `references/character-arc.md`。
> STEP 3 与 STEP 6 前加载。`character-design.md` 给出「人物有哪些要素」，
> 本文件给出「人物怎么变、以及人物之间如何共同论证主题」。

## 1. 弧光动态链

```text
Ghost / Wound（旧伤）
  → Lie（为保护自己相信的错误信念）
  → Want（由 Lie 驱动的具体外在目标）
  → Need（他真正需要、但拒绝承认的真相）
  → 压力递增的选择（每次选择都让 Lie 更难维持）
  → 自我揭示（在不可逆的两难中被迫看见真相）
  → 新平衡（按 Truth 重新行动，或拒绝真相而坠落）
```

关键因果：**Want 是「以为能治愈旧伤的手段」，不是随便一个目标**。
如果删掉 Wound 后 Want 依然成立，说明人物是功能件不是人。

三种弧光：

| 类型 | 轨迹 | 适用 |
|---|---|---|
| 正向弧 | Lie → Truth，人物改变 | 成长、觉醒、救赎 |
| 负向弧 | 拒绝 Truth，越选越深 | 悲剧、黑化（《教父》Michael） |
| 平光弧（flat） | 人物已持 Truth，改变的是周围世界 | 爽文/短剧主角、侦探、导师型主角 |

> 竖屏短剧大量使用平光弧：主角一出场就「已看透」，靠行动改变局势。
> 这**不等于没有弧光**——平光弧的张力来自「世界为他付出什么代价」，
> 仍须在 `series-design.md` 的人物弧线里写出代价递增。

## 2. 人物 = 压力下的选择

硬规则：

1. 人物真相**只在两难且不可逆的选择中揭示**。自述、旁白、他人评价一律不算证据。
2. 两难必须是**两种都想要 / 两种都怕失去**的价值冲突，不是「明显对 vs 明显错」。
3. 每次选择必须留下**可见代价**（失去一个人、一个身份、一条退路）。
4. 选择后的行为必须与之前**不同**，否则视为无效选择。

> 与 `creative-principles.md`「Character Choice > Plot Convenience」、
> `episode-structure.md` §4 的「A 牺牲 B / 代价 / 风险 / 后果」是同一条规则的不同层次：
> 那里管单集选择，本文件管全剧选择链的因果连续性。

检验：把人物所有台词删掉，只看他的选择与后果，还能说出他是谁吗？

## 3. 人物网（Character Web）

不要逐个孤立设计角色。**每个主要人物都是对同一个核心问题的一种回答**
（见 `premise-theme.md` §4）。

| 主题功能 | 作用 | 与主角的关系 |
|---|---|---|
| 对手 / 镜像 | 持有主角 Lie 的**成功版本**，展示「照这样走下去会变成什么」 | 主角最不想成为的人 |
| 盟友 | 持 Truth 但无力执行，提供真相而不代主角做选择 | 让真相可被听见 |
| 诱惑者 | 提供一条更轻松的 Lie 路径 | 每次出现都让选择更贵 |
| 反面示范 | 已经为同样选择付过代价的人 | 把后果提前具象化 |
| 代价承担者 | 主角的选择最终落到谁身上 | 让主题的道德后果可称量 |

配置规则：

- 至少 1 个**镜像对手** + 1 个**代价承担者**。
- 每增加一个人物，先写「他对核心问题的回答」，再写外貌与身份。
- 任何人物若与主角的价值回答完全相同，合并或删除（工具人检查）。

## 4. 弧光拆到分集节拍

弧光不是最后一集才发生，必须铺成分集可检验的选择链：

| 粒度 | 要求 | 对接 |
|---|---|---|
| 每场戏 | 一次价值极性变化（+/−） | `story-anatomy.md` §2 |
| 每集 | 一次**微选择**（暴露 Lie 或松动 Lie） | `workflow.md` STEP 7、`episode-structure.md` §4 |
| 每 5 集 | 一次**不可逆选择**（退路被切断） | `series-design.md` §2 小 Arc |
| 全剧 | 高潮的**终极选择** + 结局道德后果 | `premise-theme.md` §7 |

`drama-context.md` 八幕模板的「蜕变 / 终局」对应自我揭示与主题兑现；
90 秒体裁下，微选择必须靠**动作与物件**外化（手停在门把上、把证据撕掉），
不靠内心独白——该约束见 `drama-context.md`「情绪外化」，与本文件不冲突。

## 5. 输出格式（STEP 3 追加项）

```text
【每人一张弧光卡】
人物 / 主题功能 / Ghost-Wound / Lie / Want / Need / Truth
关键选择链：集号 → 两难（A vs B）→ 选择 → 可见代价 → Lie 状态
自我揭示场：集号 + 触发事件
新平衡或坠落：结局行为（具体到动作）

【人物网对照表】
人物 / 对核心问题的回答 / 持有价值 / 结论判决 / 与主角的价值差
```

## 6. 边界

- 不重复 `character-design.md` 的六要素清单（Want/Need/Flaw/Secret/Choice/Change）
  与独立驱动力四问；本文件只定义它们之间的**因果与变化机制**。
- 不重复 `quality-control.md` 的打分；自检 Q5 / Q13 / Q18 由
  `rewrite-workshop.md` 按稿次归层调用。
- 影片级人物分析（如 Michael 的负向弧）见
  `ai-video-director/references/18-film-analysis-archive.md`。
