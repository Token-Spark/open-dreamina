# 影片分析档案：风格校准与镜头句式库

> 专业知识层 `18`，服务 STEP 1（风格校准）与 STEP 4 / STEP 8（镜头方案设计）。
> 用途：**在写分镜之前建立可复用的镜头方案**，而不是凭感觉写 Prompt。
> 逐镜头拆解表是分析产物，不进 `shots.md`、不进 `drama lint`。

## 1. 为什么分镜前要拉片

AI 生成没有现场二次创作，导演必须提前想完镜头。
最可靠的参照不是形容词（「电影感」「高级」），而是一部片子里
**某个具体手法在什么条件下成立**。

> 每部影片至少挑三个场景做逐镜头分析，把电影拆到镜头层面，而不只是理解剧情。

## 2. 剧作五维度（先看懂故事，再拆镜头）

| 维度 | 要回答什么 | 依据 |
|---|---|---|
| 人物 | 主角想得到什么？害怕失去什么？真相在哪个不可逆选择里揭示？ | `short-drama-creator/references/character-arc.md` |
| 结构 | 关键事件有哪些？激励事件 / 危机 / 高潮在哪？ | `short-drama-creator/references/story-anatomy.md` §1 |
| 场景 | 每场的目标与处境发生了什么变化？价值极性怎么翻？ | 同文件 §2 |
| 对白 | 说出来的与真正想表达的是否一致？谁掌握信息优势？ | `short-drama-creator/references/narrative-craft.md` §6 |
| 镜头 | **为什么用这个景别、角度、运镜和剪辑方式？** | 本技能 `12`–`15` |

## 3. 逐镜头拆解表（每片 ≥3 场）

| 镜号 | 时码 | 景别 | 机位 / 角度 | 运镜 | 时长 | 画面内容 | 台词与潜台词 | 声音 | 剪辑点理由 | 价值变化 | 叙事功能 |
|---|---|---|---|---|---|---|---|---|---|---|---|

填写规则：

1. 证据与解读分离：画面事实写 `[证据]`（可指到时码 / 帧），推断写 `[解读]`，
   镜头设计决策只能基于证据（与 `viral-remake` 证据优先一致）。
2. 剪辑点理由必须落到默奇六原则之一（见 `15-editing-decision-and-murch.md` §2）。
3. 价值变化写「价值对 + 起止极性」，不写「情绪变好了」。
4. 每场结束写一句**可复用句式**：手法 + 成立条件 + 可用在我作品的哪个场景。

## 4. 案例片库（起始片单）

| 影片 | 镜头设计上重点看什么 | 建议精读段落 |
|---|---|---|
| 《让子弹飞》 | 人物如何通过语言与行动争夺主动权；观众在信息不对称中不断修正判断；对白场的正反打与节奏 | 开场列车劫持；策略博弈段落 |
| 《邪不压正》 | 建筑、街道、屋顶与人物运动如何塑造视觉世界；场景本身参与叙事 | 屋顶段落、街巷追逐 |
| 《教父》 | Michael 靠选择而非解释完成人物塑造；象征性镜头；交叉剪辑与声画对置 | 餐厅枪杀；**洗礼交叉剪辑** |
| 《西西里的美丽传说》 | 少年限制性视角如何影响观众认知；小镇群体作为隐性角色；间接视点 | 少年窥视段落；群体注视段落 |

补充：按「对白 / 动作 / 情绪 / 转场」各挑一段，兼顾长镜头与蒙太奇，
避免片库只覆盖一种镜头句式。

## 5. 文学手法 → 视听手法转译索引

| 文学手法 | 视听对应 | 本技能落点 |
|---|---|---|
| 内视点 / 心理描写 | 视点镜头、反应镜头、物件特写 | `14` |
| 意识流 / 回忆 | 蒙太奇、匹配剪辑、色彩弧线切换 | `15` / `12` §4 |
| 比喻 / 象征 | 视觉母题、意象系统、重复构图 | `12` §4 |
| 情绪描写 | 景别递进、光比变化、结构性静默 | `12` / `15` §4 |
| 环境烘托 | 场面调度、画外空间、场景参与叙事 | `12` §5 / `13` §5 |

## 6. 分析结论如何回写分镜设计

| 结论类型 | 写到哪 | 具体动作 |
|---|---|---|
| 人物通过选择被塑造 | 上游剧作 | 补进弧光卡的关键选择链 |
| 场景价值转折的做法 | STEP 2 Beat | 写进 Beat 的变化类型与切点时机 |
| 某景别 / 运镜为何有效 | STEP 4 | 写进视听决策表的四问答案 |
| 某切点为何成立 | STEP 8 | 写进切点表的默奇主理由 |
| 空间如何建立 | STEP 4 | 补进机位图与轴线标注 |
| 视觉母题 | 全片 | 登记进 Visual Bible 的色彩 / 道具常量（`05`） |

## 7. 归档与边界

- 归档到 `{项目根}/导演设计/片库/{slug}.md`（sidecar，与 `17` 的 `shot-design.md` 同层），按类型 / 题材建索引。
- 与商业数据复盘分工：`short-drama-creator/references/hit-methodology.md` §3.1 看 3 秒完播率 / 追剧率；
  本档案看剧作与视听五维度。两者并列、互不替代。
- 逐镜头表是**分析产物**，不写入 `shots.md`、不进 `drama lint`；
  Storyboard 与 Shot List 的交付规范见 `17`。
