# 角色表演风格（Character Performance Guidelines）

> 专业知识层 `24`，按需加载，不对应固定 STEP（主要服务 STEP 4 动作/表情设计、STEP 6 写 Video Prompt、STEP 7 镜头类型专项）。
> 处理人物情绪反应、尤其是「吃惊 / 惊吓 / 震惊」类镜头的表演设计时加载。

## 1. 核心禁令：禁止「倒吸气」表演

**定义**：人物在吃惊 / 惊吓 / 震惊时猛地倒吸一口气（sharp intake of breath / gasp reflex），
常伴随「瞪大眼 + 后仰 + 双手微抬」的套路化组合动作。

**禁止在 AIGC 视频提示词里出现**：

- 英文：`gasp`、`sharp intake of breath`、`sudden inhale`、`gasps in shock`、`chokes on breath`
- 中文：「倒吸一口气」「猛地吸气」「倒抽一口凉气」「被吓得一激灵地吸气」

**禁止近义组合暗示同一反应**：即便不写「吸」字，
「手猛地捂嘴 + 瞪大眼 + 身体后仰」三件套仍是同一套路，同样禁用。

**为什么禁用**：

- AI 视频模型把「吃惊」默认渲染成统一的「倒吸 + 瞪眼 + 后仰」三件套，极易套路化、卡通化，缺乏真实人味。
- 「倒吸气」是廉价惊讶信号，人物像被吓到的表情包，会削弱戏剧重量与情绪真实感。
- 在连拍组 / 接续镜里反复出现会破坏表演连续性——每镜都重演同一夸张反应，而非自然承接上一镜的余势（见 `22` §3 表情余势）。

## 2. 替代表演方案（按情境挑一种，宁克制勿夸张）

提供可渲染、有信息量、不靠吸气承担的替代反应：

1. **微停顿 + 定格（freeze / beat of stillness）**：先一拍不动，瞳孔微缩、视线定住，再缓慢反应。最克制的「吃惊」。
2. **延迟反应（delayed realization）**：先无反应 / 继续原有动作，半拍后缓缓意识到，目光慢慢移向刺激源。
3. **身体语言替代面部（physical instead of facial）**：手中物微顿 / 微抖、脚步顿住、肩线一沉、下颌微收、手指蜷一下、呼吸一滞（breath catches，但明确不写大口倒吸）。
4. **克制的呼吸处理**：若必须表现呼吸变化，用「缓慢呼气 / 屏息 / 抿唇」而非「吸气」；只写气息变化而不写吸气动作。
5. **视线与信息差驱动**：先看别处，再缓缓转头、目光聚焦到意外之物；用 POV / 视线（见 `14`）而非夸张表情承担惊奇。
6. **环境与声音替代**：让背景音戛然而止、物品轻响、光线变化来「替」人物反应；人物只给轻微侧目或极小的肢体反馈。

## 3. 提示词写法

- **正向写克制**：在动作 / 表情描述用
  `restrained, no gasp, holds still for a beat, eyes widen slightly (not a gasp), then slowly…`，
  并给出所选替代反应的具体动作（见 §2）。
- **明确排除**：在 `negative_prompt` 写
  `gasp, sharp intake of breath, sudden inhale, exaggerated startle`。
- **不要只靠负面词**：正面必须同时给「替代反应」的具体动作，模型才知道演什么，否则只删掉倒吸会留下空白反应。
- **与接续 / 连拍组兼容**：惊觉反应只在第一镜给一个克制起势，后续镜用表情余势承接（见 `22` §5.1），避免每镜重演夸张反应。
- **表情选词的事实源**：以角色表情九宫格（`*_PRIMARY_expressions.png`）与设定卡表情谱为准
  （见 `drama-production-playbook/references/12-character-design-sheet.md`），不每镜现编表情词；
  惊讶格一律克制版（本文件 §1/§2）。

## 4. 触发清单

凡出现以下情绪 / 情境的镜头，必须走本规则：

> 吃惊、惊吓、震惊、恍然大悟、看到意外之人 / 物、被揭穿、突发坏消息、门 / 抽屉突然打开、身后有人出声、真相揭露等一切「意外刺激 → 人物反应」的镜头。

## 5. 边界

- 本文件只管「表演怎么演」，不管景别 / 机位 / 光线（那些见 `03` / `04` / `12`）。
- 不改 `22` 的表情余势与接续纪律，只是把「倒吸」从允许的表情库里移除。
- 与 `07` 的 Emotional Shot 互补：情绪戏仍优先「少运镜、让表演承担情绪」，本文件进一步规定表演本身避免哪种套路。
