# 切点决策、默奇六原则与声画关系

> 专业知识层 `15`，服务 STEP 8。
> `08-sound-and-editing.md` 已列出 Cut / Match Cut / Smash Cut / Cross Cut / J Cut /
> L Cut / Montage 七种剪辑类型；本文件只回答**「为什么在这一刻切」**，不重列类型。

## 1. 切点的六个时机

| 时机 | 判据 |
|---|---|
| 眨眼 | 人物眨眼是天然的注意力重置点，切换最不被察觉 |
| 心理完形 | 观众刚把信息拼完整、得出判断的瞬间 |
| 动作峰值 | 动作做到一半切，由下一镜完成（动作接动作） |
| 视线引导 | 人物看向画外 → 下一镜给所见（或故意不给，制造信息差） |
| 信息饱和 | 该镜头的信息已被读尽，再多一秒就是拖 |
| 情绪转折 | 场景价值极性翻转那一拍（与 `short-drama-creator/references/story-anatomy.md` 对齐） |

**反例**：镜头「放够了时间」才切、按固定秒数切、按台词说完切——都不是理由。

## 2. 默奇六原则（切点优先级）

《眨眼之间》给出的经验权重，用于判断一个切点「值不值得」：

| 优先级 | 原则 | 权重 | 要保什么 |
|---:|---|---:|---|
| 1 | 情感 Emotion | 51% | 这一刻观众该感受什么 |
| 2 | 故事 Story | 23% | 信息是否推进了叙事 |
| 3 | 节奏 Rhythm | 10% | 整段的呼吸与快慢 |
| 4 | 视线 Eye-trace | 7% | 观众的眼睛落在哪，下一镜接得上 |
| 5 | 二维平面 Two-dimensional plane | 5% | 构图平衡、银幕方向不冲突 |
| 6 | 三维空间 Three-dimensional space | 4% | 人物空间关系连贯（见 `13` 轴线） |

**「最不坏切换」决策模型**：理想切点六项全满足几乎不存在。
优先保住前两项（情感 + 故事），必要时牺牲后四项；
反过来「为了轴线正确而切在情绪没到的时候」是本末倒置。

每个切点必须给出**主理由**（六原则中的一项）并写入 sidecar。

## 3. 视觉连续性

- 动作接动作：动作跨镜完成，起止姿势一致。
- 视线匹配：看向画外 → 下一镜给所见，方向一致。
- 图形匹配：形状 / 色彩 / 运动方向承接（Match Cut 的依据）。
- 30 度规则：相邻镜头的机位角度变化 ≥30°，否则观感像跳帧；
  除非是刻意强调（同机位推进表现压迫）。
- 与 `05-continuity-and-lock.md` §1 的站位 / 手位 / 朝向连续性、
  `09-pipeline-and-qc.md` 的 Continuity QC 项一起执行。

## 4. 声画关系

| 手法 | 用法 |
|---|---|
| 声画同步 | 声音确认画面，稳定、可信 |
| 声画对位 | 声音与画面互相补充信息（画给表情、声给事件） |
| 声画错位 / 对置 | 声音与画面情绪相反，产生反讽 |
| 声音先导（J Cut） | 下一场声音先入，牵引观众预期 |
| 声音延后（L Cut） | 上一场声音延续，留住余味 |
| 结构性静默 | 在情绪最高点撤掉全部声音，比配乐更重 |

> 《教父》洗礼交叉剪辑是「交叉剪辑 + 声画对置 + 音乐统一」的复合范本：
> 画面是神圣仪式，剪辑指向同时发生的杀戮，音乐把两层缝成一个主题陈述。
