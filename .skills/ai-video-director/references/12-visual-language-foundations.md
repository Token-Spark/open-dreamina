# 视听语言基础：画框、焦距景深、灯光色彩、场面调度

> 专业知识层 `12`，按需加载，不对应固定 STEP（主要服务 STEP 4）。
> `03-shot-size-and-choice.md` 给出景别枚举、`04-camera-and-composition.md` 给出
> 运动枚举与构图清单；本文件只补「为什么这样选」的原理与决策依据，不重列枚举。

## 1. 一个镜头先回答四问

设计任何镜头前，先写四句：

```text
让观众知道什么（信息）
让观众感觉什么（情绪）
让观众忽略什么（信息控制）
让观众期待什么（下一镜的钩子）
```

四问答不上来的镜头，即使画面好看也是废镜（与 `09-pipeline-and-qc.md`
「仅好看但未完成叙事功能视为失败镜头」一致）。

## 2. 画框与构图

| 概念 | 用法 | AI 生成注意 |
|---|---|---|
| 画内 / 画外空间 | 画外空间制造悬念（门后、镜头外的人）；只给声音或反应，不给画面 | 生成模型默认补全画外信息，需在负面词或描述里明确「不出现」 |
| 开放 / 闭合构图 | 开放构图让视线指向画外（不安、延续）；闭合构图自足（了结、压抑） | 用留白方向与人物朝向控制 |
| 银幕方向 | 左→右 / 右→左 的运动方向承载追逐、对立、回归 | 与 `07-shot-type-guide.md` 的 Screen Direction 规则联动 |
| 平衡 / 失衡 | 失衡构图先于事件发生，预告关系破裂 | 与 `04` 的 Negative Space / Symmetry 项对接 |
| 画幅比心理 | 9:16 竖向压缩水平关系、强化身体与距离；16:9 横向容纳群像与空间 | 竖屏慎用双人对称，改用前后景 + 正反打 |

> 竖屏不是「横屏裁两边」：竖向画框里**距离**靠前后景而非左右位置表达，
> 权力关系靠机位高度与景别差，不靠横向站位。

## 3. 焦距与景深

| 焦距 | 透视 | 叙事用途 |
|---|---|---|
| 广角（24–35mm） | 夸张纵深、近大远小 | 空间压迫、人物被环境吞没、运动冲击 |
| 标准（50mm） | 接近人眼 | 对白、日常、可信 |
| 长焦（85mm+） | 压缩空间、背景贴近 | 偷窥、孤立、两人看似贴近实则隔绝 |

景深是**信息控制工具**，不是清晰度设置：

- 浅景深：只让观众看一个信息（情绪特写、秘密道具）。
- 深焦：前景 / 中景 / 后景同时可读，让**调度**承担叙事（谁在前、谁在后即关系）。
- Rack focus（移焦）：不切镜头完成一次注意力转移 = 一次场景内转折。
- 焦距 × 景别 × 机位联动：同为中近景，广角贴近拍会变形且带环境，
  长焦远距离拍会剥离环境。三者必须一起写进 Prompt，否则模型自行补齐会与意图不符。

`05-continuity-and-lock.md` 把 `35/50/85mm` 定为全局镜头常量；
本文件要求**逐镜说明选择理由**，全局常量是默认值而非免答理由。

## 4. 灯光与色彩

- 三点布光：主光（造型）/ 补光（控制光比）/ 轮廓光（分离人物与背景）。
- **动机光**：光源必须在场景里有出处（窗、灯、火、屏幕）。凭空打光会破坏真实感，
  也是 AI 生成最常见的「好看但不成立」来源。
- 光比：高光比 → 悬疑、道德暧昧；低光比 → 平实、日常、喜剧。
- 硬 / 软光：硬光强调质地与裂纹（审讯、真相）；软光柔化（回忆、温情）。
- 色温动机：冷暖对撞必须对应叙事双方，不能只为「好看」。
- **色彩弧线**：全片主色随价值变化迁移（如冷→暖），逐集在 Visual Bible 登记，
  禁止逐镜随意换色（`05` 的 Color 常量是基线）。

## 5. 场面调度（Mise-en-scène）

**调度先于机位**：先定人物在哪、怎么走、看谁，再决定机器放哪。

五个可调层：

```text
区域（谁占哪块空间）/ 走位（起止与路径）/ 视线（看谁、避开谁）
道具（握着什么、放下什么）/ 景深分层（前中后景各放什么信息）
```

- 距离即关系：靠近 / 远离是一次无需台词的价值变化。
- 高度即权力：坐 / 站、俯 / 仰必须与设计意图一致。
- 前景阻隔（栏杆、门框、人群）：把关系外化成可见障碍。
- 镜头与调度配合的三种基本式：
  ① 静止机位 + 人物运动（观察式，适合竖屏可控生成）
  ② 运动机位 + 静止人物（揭示式）
  ③ 二者同动（跟随式，AI 生成风险最高，需 Keyframe 门禁）

> AIGC 约束：单镜一个主要动作（`07-shot-type-guide.md` §1）。
> 复杂调度优先拆成「静止机位 + 一人一次移动」的多镜组合，用剪辑制造复杂度。

## 6. 输出（挂到 STEP 4）

每个 Scene 附加一张视听决策表：

```text
Scene ID / 四问答案 / 画框策略 / 焦距+景深及理由 / 动机光与色温 / 色彩弧线位置
调度层：区域 / 走位 / 视线 / 道具 / 景深分层
机位选择理由（为什么这里，而不是别处）
```
