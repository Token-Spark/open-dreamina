# 空间叙事、180 度线与机位图

> 专业知识层 `13`，服务 STEP 4 / STEP 8。与 `07-shot-type-guide.md` 的正反打、
> Master Shot→Coverage、Screen Direction 规则对接，不重述其条文。

## 1. 为什么必须先定空间

传统剧组可以在现场靠导演、摄影、演员共同二次创作；
AIGC 制作没有现场——**空间关系必须在生成之前写死**。
观众看不懂谁在谁对面，再好的单镜也组不成戏。

## 2. 180 度线（轴线）

- 定义：由两人（或运动主体）视线 / 运动方向构成的假想线；机位须留在同一侧半圆内。
- 越轴后果：人物左右位置反转，观众误以为两人掉头或空间翻转。
- 四种**合理越轴**（必须显式写明，不能无声跨过）：
  1. 中性镜头：骑轴拍（正对 / 背对轴线）作为过渡。
  2. 运动跨越：镜头内人物或摄影机连续移动跨过轴线（一镜完成，不得靠切）。
  3. 插入切出：用一个与轴线无关的插入镜头（道具 / 空镜）重置空间认知。
  4. 建立新轴线：先用全景重新交代位置，再在新轴上开拍。
- 与 `07-shot-type-guide.md` 的 Screen Direction（左→右连续）联动：
  轴线管机位，银幕方向管运动。

## 3. 三角形机位原理

以轴线为界，机位可落在同一侧的三角形顶点群内：
`外反打 / 内反打 / 骑轴 / 侧面双人 / 过肩(OTS) / 单人正反打`。
同一场戏的机位编号必须落在同一侧；`07` §3 / §7 已给出这套镜头的用法，
本文件只管**空间合法性**。

## 4. 机位图（Floor Plan）绘制规范

每个 Scene 必须附一张文字版机位图（无法画图时用 ASCII / 表格）：

```text
场景：老宅书房 · 夜
轴线：A（窗边）←→ B（门口）    [A 在画面左，B 在画面右]

             [窗]
              A
       C1 ●  ↘   ↙  ● C2      （C1/C2：轴线同侧，外反打）
              │
       C3 ● ──┼── ● C4        （C3：骑轴中性镜头；C4：越轴，禁用）
              B
             [门]

Screen Direction：仆人自右向左入场
运动路径：A 起身 → 走向 B（前景→中景，止于中景）
```

必标四项：**轴线**、**机位号与所在侧**、**视线箭头**、**Screen Direction / 运动路径**。
机位号与 Shot ID 要在 `shot-design.md` sidecar 中一一对应（见 `17`）。
机位图须与已批准的关系关键帧用同一套站位与轴线侧（`19` §3），并与室内布局总览图的朝向编号一一对应、绑定对应全景锚点 ID（`20` §5）——设计稿机位与生成用参考图不能各说各话。

## 5. 空间即叙事

| 手法 | 效果 |
|---|---|
| 距离 = 关系 | 两人越靠越近 / 越退越远，替代台词交代关系变化 |
| 高度 = 权力 | 谁站谁坐、俯仰角差，是权力关系的可视化 |
| 画外空间 | 只给声音 / 反应不给画面，制造悬念与看不见的威胁 |
| 场景参与叙事 | 建筑、街道、屋顶、门框主动塑造处境（参考《邪不压正》的屋顶空间） |
| 空间认知三阶段 | 建立（建立镜头）→ 维持（守轴线）→ 有意打破（唯一一次越轴要有叙事理由） |

> 观众对空间的认知是**被建立出来的**，不是天然存在的。
> 没有建立镜头就直接正反打，是 AI 短剧最常见的空间崩塌来源。
