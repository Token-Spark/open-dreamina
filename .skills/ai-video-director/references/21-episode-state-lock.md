# 集内状态锚点：单集妆造 / 陈设 / 道具在场的一致性

> 专业知识层 `21`，服务 STEP 5（一致性资产）、STEP 9（门禁）与 STEP 10（交付）。
> 位于 `drama-production-playbook/references/04-consistency-strategy.md` 五层锚点的
> **第 5 层（最细、生成时最后覆盖）**。与 `19`/`20` 并列、互不替代：
> `19` 锁「人站在哪」，`20` 锁「房间结构长什么样」，**`21` 锁「这一集里他穿什么、屋里摆了什么」**。

## 1 为什么四层锚点仍会崩

现有锚点的粒度是「角色 + 集段」与「场景 primary」：

| 现象 | 根因 |
|---|---|
| 同集第 3 镜换了外套，第 7 镜又换回来 | 造型只锁到「集段」粒度，没有本集专属参考 |
| 袖口污渍在第 5 镜跑到领口，或时有时无 | 污渍属本集剧情状态，跨集锚点不承载 |
| 开头卧病在床，中段人物再入画时床没了、输液架消失 | 场景 primary 锁「房间长什么样」，不锁「本集陈设状态」 |
| 半身照做种子，镜头一转就换脸、换衣服 | 单角度单裁切的种子没有其它视角信息，模型转向即自由发挥 |
| 跨集复用上一集的关系帧，人物穿着上一集的衣服 | 关系帧只按空间状态切版本，没按妆造切 |

结论：**跨集锚点解决「这个人 / 这个房间是什么」，集内锚点解决「这一集此刻是什么样」**。
两者都要，且集内锚点在生成提示里优先。

## 2 触发条件（命中任一即必须有集内状态锚点）

| # | 条件 |
|---:|---|
| 1 | 同一集内同一角色出现在 ≥3 个镜头（含正反打、POV） |
| 2 | 本集妆造与角色 primary / 上一集不同（换装、受伤、染血、湿身、病容、卸妆） |
| 3 | 妆造带**可指认细节**：污渍、血迹、破损、缝线、配饰（戒指 / 耳环 / 发簪 / 腕带） |
| 4 | 同一集内妆造发生**变化**（中途撕破 / 染血 / 脱外套）——变化前后各锁一套 |
| 5 | 场景本集有**非常设陈设**：病床、输液架、药碗、灵位、堆叠行李、雨夜积水 |
| 6 | 陈设 / 道具**必须在后续镜头继续在场**（前镜有床，后镜人物仍在该房间） |
| 7 | 关键道具随剧情改状态（信被撕、花瓶碎、手机碎屏） |

豁免：纯特写（背景与服装细节不可辨）、仅 1 镜且无近景的过场角色。

## 3 三类产物（不要混）

| 产物 | 锁什么 | 资产 ID | 是否作生成参考 |
|---|---|---|---|
| **集内妆造三视图** | 款式 / 颜色 / 面料 / 污渍位置 / 破损 / 配饰 / 发型 / 妆容 | `char_{角色}_ep{xx}_{造型}_turnaround` | **是**：视频与关键帧唯一人物参考 |
| **妆造细节板**（可选） | 污渍 / 破损 / 配饰**特写**，供人工逐镜核对 | `char_{角色}_ep{xx}_{造型}_detail` | **否**：拼贴板进参考会污染构图 |
| **集内场景状态图** | 本集陈设摆位：床 / 输液架 / 药碗 / 灯 / 杂物 | `scene_{场景}_ep{xx}_{状态}` | **是**：该集该状态下的场景参考 |

道具随剧情改状态时用 `prop_{道具}_{状态}`（如 `prop_letter_torn`），仍走 `prop_` 前缀。

### 3.1 代码事实（别发明前缀）

`ASSET_ID_RE = (char|scene|prop|crowd|icon|voice)_...`（`drama/parser/shots_parser.py`、
`drama/qc/audit_refs.py`）。集内锚点**必须寄生在白名单前缀里**：

- 用 `char_*_turnaround` / `scene_*` / `prop_*` → 进 `drama spec` 的 refs、进 `drama assets` 审计；
- 发明 `state_*` / `wardrobe_*` / `look_*` → 被白名单**静默过滤**，审计看不见，等于未登记
  （`rel_*` / `loc_*` 的登记与手工组装见 `19` §8，本文不重复）。

`CHARACTER_SLOT_TURNAROUND_ONLY = True` 只作用于**角色槽**：角色槽里的 `char_*` 若不以
`_turnaround` 结尾会被丢掉。所以 `..._detail` 天然不进参考——这正是我们要的；
但**不要把半身照 / 细节板塞进场景槽或道具槽**绕过过滤，那是漂移源。

## 4 生成顺序

```text
角色 primary（跨集身份，固定 seed）
  → 集内妆造三视图（char_*_ep{xx}_{造型}_turnaround，以 primary 作 img2img 基准）
  → 妆造细节板（可选，从三视图裁切或特写重绘，仅供人工核对）
场景 primary（跨集外观）
  → 集内场景状态图（本集陈设，以 primary 派生）
  → 室内布局 / 全景锚点（20，室内多角度时）
  → 关系关键帧（19，多人 / 共现时；必须画在**本集妆造**上）
  → 单镜关键帧 → 视频
```

- 集内妆造**必须早于关系帧**：关系帧里人物穿着一旦错，复用它的所有镜头一起错。
- 关系帧版本与「集 + 妆造」绑定：跨集复用前先确认妆造未变，变了就出 `v2`（见 `19` §4）。
- 集内状态图从 primary **派生**，不重新文生图；否则房间结构另起一套（`20` §4 同理）。

集内妆造三视图提示词骨架（图生图）：

```text
three-view character turnaround (front / side / back, full body) of {角色},
same face and hair as the reference portrait, wearing {本集造型不可变项},
{污渍 / 破损 / 配饰按位置写死一次}, neutral grey background, even lighting,
no props, no text

以角色 primary 作 img2img 基准；固定 seed；尾部逐字拼接风格四常量
```

要点：**只在生成锚点这一次把服装写死**，且写清位置（左袖口内侧铜钱大污渍 / 右膝破洞）；
后续镜头一律不再重复（§5）。

## 5 提示词纪律：锁定之后只引用，不描述

本层最容易错、也最容易修的一条：

> **妆造已被图片锁定 → 提示词不得再写服饰 / 妆造描述。**

原因：文字与参考图是两路互相竞争的条件。写了「白色棉质睡裙，左袖有咖啡渍」而参考图是
灰蓝病号服时，模型可能各取一半——款式对、污渍跑到右袖，或整套换掉。

| | 写法 |
|---|---|
| ✅ 正例 | `Keep the character's face, hair, makeup and costume exactly as in the reference image.` ＋ 本镜动作 / 表情 / 走位 |
| ❌ 反例 | `...wearing a white cotton nightgown with a coffee stain on the left sleeve and messy hair...` |
| ❌ 半对 | 引用图 ＋「同样的白裙但更旧一点」——相对修饰同样触发重绘 |

落地口径：

1. **人物行只写身份项**：英文名 ＋ 本镜身体 / 表演状态（`exhausted, sitting up slowly`）；
   服装、发型、妆容、配饰、污渍一律留给参考图。`drama compile` 段 2 的角色锚点逐字取自
   人物行——人物行写了服饰，等于把冲突写进了 prompt。
2. **一致性锚句逐字固定**：`Keep the character's face, hair and clothing identical to the
   reference image.` 禁止追加服饰补语（`...identical, with a silk scarf` 也算冲突）。
3. **场景同理**：陈设已由集内状态图锁定 → 只写「延续参考图的房间陈设与道具在场情况」，
   不重述「床边有输液架、桌上有药碗」；重述会让模型挪位或复制成两份。
4. **必须写服饰的唯一情形**：本镜内发生造型**变化过程**（撕破 / 染血 / 脱外套）。
   写「变化」不写「样式」（`tears the left sleeve open around 2s`），并在同镜或下一镜
   切到对应新状态锚点（换 `*_turnaround`，不靠文字描述新衣服）。
5. **没有锁定图就不要硬写服饰**：先补集内妆造三视图。堆形容词不是一致性策略，是放弃锚点。

## 6 种子纪律：三视图，不要半身照

| 允许 | 禁止 |
|---|---|
| `*_turnaround`（正 / 侧 / 背全身）作视频与关键帧参考、首帧 | `_halfbody` 半身照作种子 / 参考 / 首帧 |
| 集内妆造版 `*_ep{xx}_..._turnaround` | 单张剧照、上一版成片截帧、社媒参考图 |
| 角色 primary 作**生成三视图**的 img2img 基准 | 多图拼贴板（`_detail`、布局总览、九宫格） |
| 场景 primary / 集内状态图作场景参考 | 把半身照塞进场景槽 / 道具槽绕过过滤器 |

理由：三视图一次给出正 / 侧 / 背三个视角的身体与服装信息，模型转向时有依据；
半身照只有单一角度与单一裁切，一转侧面就靠编——这是「同一角色每镜都像换了个人」的主因。

## 7 生成门禁（硬）

触发 §2 命中，以下任一不成立 → 任务标记 `BLOCKED`，不得生成：

1. 集内妆造三视图不存在 → 先生成并批准，不得用 primary 或半身照顶替。
2. 存在但未批准（素材审阅中心未通过）→ 等批准。
3. 引用了错误集 / 错误造型的三视图（上一集、上一版）→ 改正后重试。
4. 集内状态已变（染血 / 撕破 / 卸妆）却仍引用变化前的锚点 → 补新状态锚点。
5. 场景陈设需延续而集内状态图缺失 → 先补状态图。
6. 妆造正确但视频里仍漂移 → **先修锚点或改镜头**，不得靠反复抽卡。

顺序见 §4，不可颠倒。

## 8 QC 验收

- **资产 QC**：三视图三面齐全，款式 / 颜色 / 污渍位置 / 破损 / 配饰与剧本一致；
  细节板与三视图不矛盾；`_detail` 未被当作参考使用。
- **关键帧 QC**：妆造逐项对齐集内锚点（款式、颜色、污渍位置、发型、妆容、配饰、伤痕）；
  陈设在场（该在的都在，不该有的都没有）。
- **视频 QC**：跨镜妆造漂移（换外套 / 污渍左右跳 / 配饰消失）；陈设缺位或翻倍（一张床变两张）；
  道具状态与剧情不同步。
- **审片**：对照集内三视图 ＋ 状态图 ＋ shots.md；漂移 → 降档，精修提示词写明
  「回到 `char_lin_ep07_hospital-gown_turnaround` 的妆造」，不写「穿白裙」这种描述。

## 9 与 shots.md / lint 兼容

- 资产绑定行正常写 `char_*_ep{xx}_..._turnaround` 与 `scene_*_ep{xx}_...`，**两者都在白名单内**，
  会进 `drama spec` refs 与 `drama assets` 审计——本层不像 `19`/`20` 需要绕开 spec。
- `shots.md` 模板、列序、必填行、lint 硬规则一律不动（`17` §5 管线保护）。
- 语义元数据（本集造型说明、污渍位置、陈设清单、变化点、批准状态）写
  `{项目根}/导演设计/EPxx/shot-design.md` sidecar：

```markdown
## EP07 集内状态
- 妆造：`char_lin_ep07_hospital-gown_turnaround` / 平台 asset_id `xxxx` / 已批准
- 不可变细节：左袖口内侧铜钱大污渍；右膝纱布；无耳饰
- 陈设：病床（靠窗）、输液架（床右）、床头柜药碗
- 变化点：EP07-S12 起右膝纱布渗血 → 新锚点 `char_lin_ep07_hospital-gown-injured_turnaround`
```

`drama assets EP07` 会审计这些 id 的 asset_id 是否落位，缺一条即为无参考生成。
