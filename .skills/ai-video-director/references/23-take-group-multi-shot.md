# 23 连拍组：一次任务生成多个镜头

> 专业知识层 `23`，服务 STEP 6（写提示词）、STEP 9（生成门禁）、STEP 10（交付）。
> 与 `22`（镜头接续）是同一条问题的两个解法：`22` 解决**不同任务之间怎么接**，
> 本文件解决**能不让它跨任务**。
> 与 `19`（关系帧）、`20`（房间锚点）、`21`（集内状态）并列：那三层保证「每镜单独看是对的」，
> `22` 保证「连起来是一条」，本文件保证「连起来这件事根本不靠拼」。

## 1 结论先行

> **Seedance 2.5 单次生成支持最长 30 秒。同一场、同一时段的连续镜头，优先合并成一次生成（连拍组），
> 而不是每个子镜头独立出一个任务。**

独立生成 N 个镜头 = N 次重新猜人物站位、重新猜光从哪来、重新猜妆造状态；
每次都要靠 `22` 的英文入场句把状态"说"回去，说漏一处就跳一次。
一次生成 N 个镜头 = 模型在同一次推理里连续持有位置、光向、色温、陈设与人脸，
切点两侧是它自己接的，不存在"猜错别人的上一镜"。

三条收益，按重要性排序：

| # | 收益 | 独立生成为什么拿不到 |
|---:|---|---|
| 1 | **状态天然连续**：位置、光向、时段、妆造、道具在场、环境音底噪在一次生成内保持 | 靠文字重述入场态，重述有损；重述越多越容易被模型各取一半 |
| 2 | **动作可以切在中段而不重演**：刀举到一半切走，下一镜从这一拍接着走 | 每镜从 0 帧起，模型倾向把动作从头演一遍（`22` §1 症状表） |
| 3 | **试错成本从 N 次降到 1 次**：接不上时整组重出，而不是逐镜缝合 | N 个镜各抽 2 次 = 2^N 条待拼接素材，缝合处的瑕疵永远留着 |

## 2 什么能合、什么必须拆

**判据只有一句：这一组镜头是不是"同一次连续拍摄能拍下来的东西"。** 是 → 合；不是 → 拆。

### 2.1 能合（按收益排序）

| 情形 | 判据 | 备注 |
|---|---|---|
| 动作接动作（A 级硬接） | 同场、同时、同一动作流，切点落在动作中段 | 收益最大的一类；`22` 里最难写对，这里直接消失 |
| 正反打对白（双人） | 同场、共享站位、无复杂口型特写 | 合并能消掉越轴与肩线翻边；但必须用 `Shot N: over-the-shoulder on A` 明示机位，否则两人会被塞进同一画面 |
| 跟拍 / 连续移动 | 走→转身→停下，屏幕方向不变 | 独立生成最常见的"方向反了"在这里不会发生 |
| 同场换机位（30° 内） | 人物相对位置不变、光向不变 | 切点写 `HARD CUT`，别写 `then` |
| 空镜 / 环境序列 | 同场、无人物或人物不主导 | 风险最低，可以用到组时长上限 |

### 2.2 必须拆（独立任务）

| 情形 | 原因 |
|---|---|
| 跨场 / 跨时间（C 级断接） | 换空间就是换生成上下文；除非把转场本身设计成组内一个镜头 |
| 多人物理接触（对打、搀扶、拥抱）、三人以上群像 | 多人同镜是最高风险项（`03-seedance-best-practices.md` 经验 1），合并会让瑕疵扩散到整组 |
| 需要精确咬口型的台词特写 | 口型是单镜强约束，组内一旦漂移，整组作废 |
| 单镜有独立复杂运镜 / 特效合成点 | 组内运镜必须简单；复杂调度单独出、单独验收 |
| 必须从已批准画面精确起幅（合成点、定格、严格对位） | 属首帧的合法用途（`22` §5.3），与连拍互斥 |

> 一个镜头内部仍然**只有一个主要动作**。连拍组是把"多个镜头"合并成一次生成，
> 不是把"多个动作"塞进一个镜头——后者是分组最常见的误用。

## 3 组规模与时长

| 约束 | 取值 | 理由 |
|---|---|---|
| 单任务总时长 | **≤ 30s**（Seedance 2.5 上限） | 只有 2.5 支持；Fast / Mini / 2.0 上限 15s，只能做 2–3 镜小组 |
| 推荐总时长 | **12–20s** | 黄金区间：省任务数，又不至于后段衰减 |
| 组内镜头数 | **2–4**（对白正反打最多 4） | 超过 4 镜，模型对切点的服从度明显下降 |
| 组内单镜时长 | **≥ 3s**，仍受 lint 2–8s 约束 | 短于 3s 的镜在组内容易被"吃掉"（少切一次） |
| 一集 90s 的组数 | 4–6 组 | 代替 18 个独立镜；不是每集都必须全部合并 |

- 上限 30s 是**参数窗口**，不是创作目标。不要为了用满 30s 硬塞镜头。
- 后段衰减是真实存在的：第 3、4 镜的人脸与一致性会弱于第 1 镜。
  所以**组内越靠后的镜头，越应该给简单任务**（反应镜、空镜、背影），重头戏放前台。
- 核对模型能力再编组：`opendreamina models --mode video` / `list_models` 看 `duration.max`。
  组总长超过模型上限 → 二分拆组，不要砍镜头时长。

## 4 提示词结构

连拍组提示词 = **一段全局（只写一次）+ 顺序镜段（每段自带机位与动作）**。
核心差异：**组内不重复身份 / 服饰 / 场景描述**，重复即漂移。

```text
[全局段] 风格常量 + 场景锚点 + 人物身份锚点（@char_id）+ 音轨纪律（同 §3.4 固定结构）
[组接续句] 仅第一镜：Continuing directly from the previous shot: {位置关系}, {动作在第几拍}, {表情余势}; {光源方位} stays the same.
Shot 1 (0.0-6.0s) — {景别}, {机位}, {运镜}：{单一动作}；{台词}
HARD CUT
Shot 2 (6.0-13.0s) — {景别}, {机位}, {运镜}：{动作从第几拍接续}；{台词}
HARD CUT
Shot 3 (13.0-20.0s) — {景别}, {机位}, {运镜}：{单一动作}；{台词}
[尾段] 负面词 + 音轨约束（全组共用，只写一次）
```

写法纪律：

1. **全局段只出现一次**。每段重复一遍"黑发、白裙、锻炉内景"→ 模型每段重新采样一次外观，接缝处必崩。
2. **每段必须有 `Shot N (起-止s)` 时间码**。只写文字不写秒点，模型不知道该切还是该连续演。
3. **切点写 `HARD CUT` 或 `CUT TO`**，独占一行。`then` / `next` / `after that` 会被理解成连续运动，
   结果是糊成一条长镜头。需要软过渡时写 `CUT TO` 并在两侧各自交代时间。
4. **第二镜起不写入场句，改写在段首一句短语**（`same room, key light still from frame left`）。
   组内的入场态由上一段自然延续，长篇重述反而诱发重置。
5. **动作拍点写"到哪一拍"**：`the knife already past his shoulder, he drives it down`，
   不写 `he raises the knife`（那是重演）。
6. **音轨按 `prompt-optimizer/references/02-prompt-templates.md` §3.4 固定结构写一次**，
   台词按段落到对应 `Shot N` 下逐字写；整组一条音轨，不能分镜各自禁乐。

正例（两镜硬接，刀落）：

```text
Cinematic realism, handheld-free static framing, warm forge interior; Venus (@char_venus_s1),
matte skin, dark braid; ambience: forge fire crackle throughout, no music of any kind.
Continuing directly from the previous shot: Venus at frame left, turned three-quarters away,
the knife already past her shoulder, jaw clenched; the forge glow still comes from frame left.
Shot 1 (0.0-6.0s) — medium, eye-level, static: she drives the knife down onto the anvil,
sparks scatter at contact. No dialogue.
HARD CUT
Shot 2 (6.0-13.0s) — close-up, low-angle, slow push-in: same room, key light still from frame left;
her hand releases the hilt and goes slack, breath audible, eyes still on the metal.
No dialogue.
```

反例：

```text
❌ 两段各自重写人物外观与场景（每段都重新采样 → 切点处换脸换光）
❌ Shot 2 写 "she raises the knife again"（动作重演）
❌ 全程没有秒点与 HARD CUT（模型糊成 13 秒一镜到底）
❌ 把两个人写成 "they face each other"（并列构图，正反打失效）
```

## 5 参数与参考

| 项 | 取值 | 说明 |
|---|---|---|
| `duration` | 组内各镜时长之和，**显式传** | 不传会落默认 5s，等于只出第一镜 |
| `frame_mode` | `reference`（显式传） | 与单镜纪律一致，见 `03-seedance-best-practices.md` 规则 5 |
| 参考图 | **整组共用一套同一版本**：`*_turnaround` + 场景 primary + `loc_*`（+ 命中时 `rel_*`） | 换版本 = 换空间，组内接不上 |
| 分辨率 | 720p 打样，定稿再 1080p | 30s 任务在 1080p 下耗时与成本明显上升 |
| 轮询 | `wait_task timeout_seconds ≥ 1200` / `--poll` 放宽 | 30s 任务比 5s 任务慢数倍，按 600s 等会误判超时 |

- 组内所有镜头共享同一段音轨设置（`generate_audio` 是整条开关，不能分镜开关）。
- 时间码之和必须等于 `duration`；不等时模型按比例拉伸，切点全部漂移。

## 6 分镜与管线兼容（代码事实，别绕）

**`shots.md` 不变。** 15 行模板、15 列列序、lint 硬规则（2–8s、18 镜）一律不动（`17` §5）——
连拍组是**生成侧编组**，不是分镜结构变更。

| 写在哪 | 写什么 | 谁读 |
|---|---|---|
| `shots.md` 总览表 / 逐镜块 | 每镜仍是独立一行、独立一块，字段与时长照旧 | lint / parse / compile / spec / 审片 |
| `shots.md`「衔接」列 | 组内第二镜起照样写入场态（`[A] 接 S03：…`）——它现在是**段内切点的描述依据**，也是裁切后逐镜验收的依据 | 人 + agent 门禁 |
| sidecar `导演设计/EPxx/shot-design.md` | 新增「连拍组表」：`TG 编号 / 包含镜号 / 各镜时长 / 组总长 / 切点类型 / 母版文件名` | 执行层编组、审片定位 |
| `tools/episode_specs/EPxx.json` | **结构不变**（仍逐镜 `shots[]`）；编组只写在执行报告里，不改 spec | 执行层按 sidecar 表合并调用 |

连拍组表格式：

```text
| 组 | 包含镜号 | 各镜时长 | 组总长 | 切点 | 母版 |
|---|---|---|---|---|---|
| TG01 | S01–S03 | 5 / 4 / 6 | 15s | 硬接 + 硬接 | EP01_TG01_15s_master.mp4 |
| TG02 | S04–S05 | 4 / 4 | 8s | 正反打 | EP01_TG02_8s_master.mp4 |
```

门禁：组内任一镜命中多人 / 室内跨机位 / 妆造状态切换 → 仍按 `19` / `20` / `21` 先备锚点，
**合组不免除锚点要求**（与"拆正反打不免除关系帧"同理）。
跨妆造状态的镜头不得同组（`21` 的锁定按镜生效，一次生成只能有一套妆造）。

## 7 母版与裁切落库

产物是一条含多个镜头的母版，**必须按切点裁成逐镜文件**，否则审片对齐、`drama qc` 与断点恢复全坏。

```text
分镜脚本/EPxx/video_renders/
├── _takes/EP01_TG01_15s_master.mp4          ← 母版，`_` 前缀不被审阅扫描
├── S01_seedance25/EP01-S01_....mp4          ← 按切点裁切，逐镜落库
├── S02_seedance25/EP01-S02_....mp4
└── S03_seedance25/EP01-S03_....mp4
```

裁切（ffmpeg，缺 ffmpeg 时如实降级为"母版 + 手工对齐"，不得假装已裁切）：

```bash
# 无损切（切点落在关键帧附近才准；有偏差时去掉 -c copy 重编码）
ffmpeg -ss 0  -to 5  -i master.mp4 -c copy S01.mp4
ffmpeg -ss 5  -to 9  -i master.mp4 -c copy S02.mp4
ffmpeg -ss 9  -to 15 -i master.mp4 -c copy S03.mp4
```

- 母版必须保留：整组重出的判断依据是"组内相对关系"，不是单镜。
- 切点漂移时先按**实际画面**切（以视觉切点为准），再回头修提示词与 sidecar 时间码；
  不要为迁就时间码把镜头切在运动中。
- 版本命名沿用 `{镜号}_seedance25/`，组重出 = 整组一起换目录，不做组内混版
  （混版等于把拼接问题又请回来）。

## 8 验收门禁（组级，先于逐镜 QC）

1. **切点数 = 设计切点数**。少切（糊成一条）或多切（多出黑场/跳切）→ 该组 `RETRY`，改提示词切点，不逐镜抽卡。
2. **切点两侧 ±0.5s 抽帧**，按 `22` §2 三主线（位置关系 / 环境 / 动作与表情）核对。
   组内仍断 = 提示词没写清切点，或单段动作过载。
3. **后段一致性**：第 3、4 镜人脸 / 妆造 / 光向与第 1 镜对比，明显衰减 → 缩组（4→2+2）。
4. **裁切后逐镜时长**与 `shots.md` 偏差 ≤±15%；同时核对 `duration` = 各段时间码之和。
5. **音轨**：整组一条轨，禁乐（`03-seedance-best-practices.md` 规则 6）、环境音跨切点连续不归零；
   台词镜台词逐字正确、口型对齐、音色与 `anchor-voice` 一致。
6. 逐镜通过后再走单镜 QC（`09`）与初审打分（shot-reviewer）——**组级验收不替代单镜评分**。

## 9 失败与降级

| 症状 | 先试 | 再试 | 最后 |
|---|---|---|---|
| 切点漂移 / 糊成一条 | 补秒点与 `HARD CUT`，缩组到 2 镜 | 二分拆组（4→2+2） | 回逐镜独立生成 + `22` 入场句 |
| 后段人脸崩 | 把重头戏前置，后段改简单镜 | 缩组 | 拆组 |
| 组内某镜动作过载 | 该镜拆成两镜（组内镜数不变则缩别处） | 该镜独立出组 | — |
| 台词口型漂 | 台词前置到段首并标说话人 | 台词镜独立出组单生成 | 换支持同步音频的模型 |

**降级不是失败**：连拍组省的是"跨任务的状态重述成本"，当一组戏本来就跨场、跨时间、
或者有强多人互动时，逐镜独立生成本来就是对的解。

## 10 边界

- 不改 `shots.md` 15 行模板 / 15 列列序 / lint 硬规则；不改 `episode_spec` 结构；要改代码另开任务。
- 不替代 `22`：组与组之间、以及拆出来的独立镜，接续仍靠入场句 + 同版本参考。
- 不新增评分维度：组级验收是生成侧门禁，进初审仍按 shot-reviewer 六维度打分。
- 不规定「一集必须全用连拍组」：混合编组（连拍组 + 独立镜）是常态。
