# 视点设计与观众信息差

> 专业知识层 `14`，服务 STEP 3 / STEP 7 / STEP 8。
> `drama-shotlist-spec.md` 要求「每集至少 1 个 POV」；本文件把这条**数量规则**
> 升级为**意图规则**：POV 必须服务于信息差，否则只是凑数。

## 1. 视点分类

| 视点 | 定义 | 镜头特征 |
|---|---|---|
| 客观 / 旁观 | 摄影机是隐形观察者 | 平视、标准焦、稳定 |
| 主观 POV | 摄影机 = 人物眼睛 | 人物视线高度、轻手持、常伴画外音 |
| 限制性视点 | 只跟随一人所知 | 反打缺席、他离场则信息断 |
| 全知 | 观众比所有角色知道得多 | 交叉剪辑、插入镜头 |
| 不可靠视点 | 所见被人物心理扭曲 | 变形焦、重复镜头、色调偏移 |
| 间接视点 | 借**他人的反应**看事件 | 事件不入画，只给反应镜头 |

## 2. 观众信息差矩阵（决定悬念 / 惊奇 / 反讽）

| | 观众知道 | 观众不知道 |
|---|---|---|
| **角色知道** | 共谋：等待他行动（张力） | 限制视角：跟随发现（代入） |
| **角色不知道** | 戏剧反讽：替他捏把汗（悬念） | 双方同时揭晓（惊奇） |

四种效果对应四种镜头策略：

- **悬念**：先给观众看「刀」，再给角色关门 → 插入镜头 + 全知视点。
- **惊奇**：与角色同时揭晓 → 限制性视点 + 反打镜头的切点后置。
- **戏剧反讽**：观众知道而角色不知 → 客观视点 + 时长略长，让观众「等着看」。
- **神秘**：角色知道而观众不知 → 只给行为不给动机，用间接视点（他人反应）替代解释。

> 《西西里的美丽传说》的少年视角是「限制性 + 间接视点」的范本：
> 小镇群体作为隐性角色，通过众人的注视与议论塑造人物，而不是旁白介绍。

## 3. 视点 → 镜头参数映射

```text
主观 POV      → 人物视线高度 / 轻手持 / 标准-广角 / 时长偏短 / 切点落在视线落点
限制性视点    → 严守该人物的轴线侧；不给他离场后的画面
全知视点      → 允许交叉剪辑与插入镜头，但要重新建立空间（见 13）
不可靠视点    → 焦段/色调/重复镜头做偏差标记，并在 Visual Bible 登记
间接视点      → 事件不入画，只给反应镜头（CU/ECU）+ 画外音
```

## 4. POV 硬规则的升级版

1. 每集至少 1 个 POV（`drama-shotlist-spec.md` 原规则保留）。
2. **该 POV 必须在 sidecar 中写明**：谁的视点、观众此刻比角色多 / 少知道什么、
   制造的是悬念 / 惊奇 / 反讽 / 神秘中的哪一种。
3. 只为凑数量而设的 POV 视为无效镜头；`09-pipeline-and-qc.md` 的 Story Function 评分项应扣分。
4. 同一集内切换视点必须有**切点理由**（见 `15`）与空间重建（见 `13`）。

## 5. 输出（挂到 STEP 8）

```text
【视点与信息差表】
镜号 / 视点类型 / 视点归属 / 观众所知 vs 角色所知 / 目标效果 / 镜头参数 / 切点依据
```
