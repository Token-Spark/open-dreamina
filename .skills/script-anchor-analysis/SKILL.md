# 剧本锚点拆解与素材创建

本技能引导智能体完成从「原始剧本」到「素材库就绪」的全流程：分析剧本 → 生成结构化锚点清单 → 自动创建创作素材至系统素材库。

---

## 适用场景

- 用户提供了一段剧本 / 分镜脚本 / 故事大纲，需要拆解出可用于 AIGC 创作的结构化素材描述。
- 用户希望将剧本中的角色、场景、道具自动录入素材库，以剧本名称作为标签统一管理。
- 用户需要一个标准化的「锚点清单」作为后续生成图片/视频时的提示词基础。

---

## 工作流程（三步法）

### 第一步：收集与确认剧本信息

1. 获取用户提供剧本全文（或分镜脚本 / 故事大纲）。
2. 与用户确认以下关键参数（若用户未提供则主动询问）：

| 参数 | 说明 | 示例 |
|------|------|------|
| 剧本名称 | 作为全局标签，贯穿所有素材 | `大语言模型二次元角色·未来城市打击加班行动` |
| 画面风格 | 整体视觉基调 | `二次元动画、赛博朋克` |
| 视频时长 | 影响时序锚点的分镜规划 | `60秒` |

3. 若用户已提供完整剧本且上述信息可从文本推断，则无需重复询问，直接进入第二步。

### 第二步：生成锚点清单

按照下方 **锚点分类体系** 逐类拆解剧本，生成完整的锚点清单。

#### 锚点分类体系

每个锚点由 **编号 + 类型 + 标题 + 描述** 组成，编号格式为 `A01`、`A02`……连续递增。

| 锚点类型 | 编号前缀 | 说明 | 对应素材库 category |
|----------|---------|------|-------------------|
| 全局风格锚点 | 风格锚点 | 全片统一画风、色调、线条、服饰风格、饱和度等视觉基调 | — （仅文案，不创建素材） |
| 主体角色锚点 | 角色·{名称} | 人物外貌、服饰、特效、表情、性格标签 | `character` |
| 场景锚点 | 场景·{名称} | 环境、视角、时间、氛围、关键元素 | `scene` |
| 构图锚点 | 构图·{名称} | 镜头视角、人物占比、景别、背景元素关系 | — （写入场景素材 description） |
| 时序锚点 | 时序 | 总时长、分镜数、单镜时长、语速、字幕说明 | — （仅文案，不创建素材） |
| 道具/细节锚点 | 道具·{名称} | 关键物品的外观、功能、显示内容 | `prop` |

#### 锚点清单输出格式

```
锚点清单 — {剧本名称}

全局风格锚点
A01【风格锚点】：{画风描述}，{色调描述}，{线条描述}，{构图风格描述}，{服饰风格描述}，{饱和度描述}

主体角色锚点
A02【角色·{角色名}】：{发型/发色}，{配饰}，{服装描述}，{特效/特征}，{表情/性格}，{定位说明}

场景锚点
A04【场景·{场景名}】：{视角}，{环境描述}，{关键元素}，{时间}，{氛围}

构图锚点
A06【构图·{构图名}】：{人物位置}，{朝向}，{背景}，{景别}，{占比}

时序锚点
A08【时序】：全片约{X}秒，共{N}个分镜，每镜{X-Y}秒，{语速说明}，{字幕说明}

道具/细节锚点
A09【道具·{道具名}】：{外观描述}，{显示内容}，{功能说明}
```

#### 拆解原则

1. **穷尽性**：剧本中出现的每一个有名角色、独立场景、关键道具都必须产出对应锚点。
2. **可生成性**：描述必须可直接作为图片/视频生成提示词使用，避免抽象表述。
3. **颗粒度**：角色锚点聚焦单个角色的完整视觉设定；场景锚点聚焦单个环境的完整空间描述；道具锚点聚焦单个物体的外观与功能。
4. **编号唯一**：所有锚点连续编号（A01~AN），不跳号、不复用。
5. **风格一致**：全局风格锚点 A01 是所有其他锚点的视觉基底，后续锚点描述不应与 A01 矛盾。

### 第三步：自动创建素材至素材库

将锚点清单中可创建为素材的条目（角色 / 场景 / 道具）通过系统 API 批量录入素材库。

#### 创建前确认

向用户展示锚点清单摘要，列出将要创建的素材条目（类型 + 名称 + 标签），获得用户确认后执行创建。

#### 素材库 API 调用规范

**基础地址**：`http://localhost:10130`（后端 API）

**创建单个素材**：

```
POST http://localhost:10130/api/v1/creation-assets
Content-Type: application/json

{
  "name": "{素材名称}",
  "category": "character | scene | prop",
  "description": "{锚点完整描述文本}",
  "tags": ["{剧本名称}"]
}
```

**响应示例**：

```json
{
  "id": "ca_xxx",
  "name": "AI少女-GPT形象",
  "category": "character",
  "description": "...",
  "tags": ["大语言模型二次元角色·未来城市打击加班行动"],
  "created_at": "2026-01-01T00:00:00"
}
```

#### 锚点到素材的映射规则

| 锚点类型 | 是否创建素材 | category | name 取值 | description 取值 |
|----------|-------------|----------|-----------|-----------------|
| 风格锚点 | 否 | — | — | — |
| 角色锚点 | 是 | `character` | 角色名称（去掉「角色·」前缀） | 锚点完整描述 |
| 场景锚点 | 是 | `scene` | 场景名称（去掉「场景·」前缀） | 锚点描述 + 关联构图锚点描述 |
| 构图锚点 | 否（合并入场景） | — | — | 追加到对应场景素材的 description |
| 时序锚点 | 否 | — | — | — |
| 道具锚点 | 是 | `prop` | 道具名称（去掉「道具·」前缀） | 锚点完整描述 |

#### 标签规则

- 所有创建的素材统一打上 **剧本名称** 作为标签，确保可通过标签筛选出同一剧本的全部素材。
- 标签值即为用户确认的「剧本名称」，不做额外截断或简化。
- 若用户后续补充了子标签需求（如按角色组、按场景组），可在创建时追加额外标签。

#### 关联图片素材（可选）

如需为素材关联已生成的图片：

1. 先通过 `POST http://localhost:10130/api/v1/assets/upload` 上传图片文件，获得 `asset_id`。
2. 创建素材时传入 `"image_asset_id": "{asset_id}"`。
3. 若暂无图片，省略该字段即可，后续可通过 `PATCH` 接口补充。

## 输出清单（交付物）

完成全部步骤后，向用户交付以下内容：

1. **完整锚点清单**（Markdown 文本，按格式输出）。
2. **素材创建结果汇总表**：

| 素材名称 | 类型 | 标签 | 状态 |
|----------|------|------|------|
| AI少女-GPT形象 | character | {剧本名称} | 已创建 |
| AI少年-另一模型形象 | character | {剧本名称} | 已创建 |
| 未来城市全景 | scene | {剧本名称} | 已创建 |
| ... | ... | ... | ... |

3. **后续操作提示**：
   - 可在「素材库」页面通过标签 `{剧本名称}` 筛选查看所有素材。
   - 可为每个素材上传参考图 / 生成图片。
   - 可基于锚点清单直接编写图片/视频生成任务的提示词。

## 注意事项

- 剧本名称中若含特殊字符（`/`、`\\`、`:`等），作为 API 标签时保持原样即可，后端会自动处理。
- 创建素材前 **务必** 向用户展示锚点清单并确认，不要跳过确认环节直接创建。
- 若素材库中已存在同名同标签素材，创建会产生重复条目；创建前可先通过 `GET /api/v1/creation-assets?tags={剧本名称}` 查询是否已有同名素材，避免重复。
- 构图锚点和时序锚点不单独创建素材，分别合并入场景描述和全局说明中。
