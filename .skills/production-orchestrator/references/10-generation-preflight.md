# 10 生成前置契约：模板 · 参考 · 编组三查

> 服务 STEP 7/8（提交关键帧与视频任务之前）。**这一关不产出新创意，只拦三类代价最高的失误。**
>
> 三条规则的原理已经写在别处（模板 `prompt-optimizer/02` §3.4/§3.5、锚点 `04-consistency-strategy`、编组 `23`），
> 但执行时分散在五六个文件里，最容易漏。本文件把它们合成一张**提交前可逐项打勾的卡**。

## 1 查一 · 提示词模板逐字遵循

### 1.1 模板是契约，不是参考

用户已定稿的模板属于**契约层**，不是"写法建议"：

| 模板 | 位置 | 不可动的部分 |
|---|---|---|
| 短剧镜头提示词九行模板 | `prompt-optimizer/references/02-prompt-templates.md` §3.4 | 行标签名、行序（镜头功能→人物→场景描述→秒级动作拆解→台词同步→音效设计→基础环境音→画面风格→特效音）、`@素材名` 引用形式、台词加引号、`//` 说明不写进提示词 |
| 多镜连拍组结构 | 同文件 §3.5 | 全局段只一次、`Shot N (起-止s)`、`HARD CUT` 独占行、尾段只一次 |
| 分镜 14 行模板 | `ai-video-director/references/drama-shotlist-spec.md` | 13 个标签的写法与顺序（+ `## EPxx-SNN` 标题）、15 列列序、枚举写法 |
| 编译 8 段 | `prompt-optimizer/references/drama-prompt-pattern.md` | 段序 1→8、段 2/4/5 锚点与台词逐字、段 8 锚句逐字 |

**只有"值"是可写的**：景别、机位、动作、台词、秒点、声源、情绪。标签与结构一律不动。

> 改模板本身（增删字段、改标签、调顺序、合并行、拆行）必须有用户明确批准，并记入
> `导演设计/EPxx/shot-design.md` sidecar。**智能体觉得"这样更清楚"不算理由**——
> 模板是下游 `drama lint` / `compile` / `parse` 与审片对齐的解析契约，不是文档排版。

### 1.2 七种"顺手优化"其实是破坏

| # | 动作 | 后果 | 正确做法 |
|---:|---|---|---|
| 1 | 改标签名（`音效设计`→`声音设计` / `Audio`） | 解析取不到，音轨等于没写 | 标签逐字照抄，内容写进值里 |
| 2 | 把音轨压成一行（或塞进一句 AUDIO） | 环境音与动作音被模型扩成配乐 | 声音工位齐全：音效设计 / 基础环境音（含动作音）/ 特效音，画面风格单列 |
| 3 | 用通用六工位模板（主体/场景/光线/镜头/风格/质感）替代短剧模板 | 丢了台词同步、音轨、锚点绑定 | 管线内镜头一律走九行模板（§3.4），画面工位走编译 8 段 |
| 4 | 重排编译 8 段顺序 | 摄影语言被当场景、台词被当动作 | 1 摄影 → 2 角色锚点 → 3 动作表情 → 4 场景锚点 → 5 台词 → 6 不入画 → 7 光感色调 → 8 一致性锚句 |
| 5 | 在锚点段 / 一致性锚句上加形容词、服饰补语 | 与参考图竞争，款式对细节换位 | 锚句逐字，不加任何补语（`21` §5） |
| 6 | 自行新增字段（"情绪曲线""转场方式""镜头动机"） | lint 不认、compile 丢弃、agent 以为写过了 | 扩展信息进 sidecar，不进 `shots.md` |
| 7 | 中英混写 / 机翻补齐未命中的中文 | 词库未命中会被丢弃，机翻污染英文锚点 | 中文必须命中 `tools/maps.py`，未命中宁缺勿错，回填词库 |

### 1.3 提交前点名（逐项打勾，不做"整体感觉对了"）

**单镜（14 行 = `## EPxx-SNN` 标题 + 13 个标签）**：镜头功能 / 资产绑定 / 人物 / 场景描述 /
秒级动作拆解 / 台词同步 / 光感 / 色调 / 构图 / 细节 / 音效设计 / 基础环境音 / 特效音
—— **13 个标签齐全且同序**，声音三行（`动作触发音` 已并入基础环境音，不再单列）。

**编译产物（8 段）**：摄影语言、角色锚点、动作表情、场景锚点、台词、不入画说明、光感色调、
一致性锚句 —— **段序不变，锚点段逐字未改**。

**连拍组（§3.5）**：全局段 1 次、每段有 `Shot N (起-止s)`、切点独占行、
时间码之和 = `duration`、尾段 1 次、第二镜起不写长入场句。

**通用**：无中文残留；负面词含 `02` §4.3 画面项与 §4.5 音乐项；
`@char_id` / `@voice_id` 是 `@` 形式而不是纯文本；台词在引号内。

## 2 查二 · 参考装配

### 2.1 四类素材各管什么

| 类别 | 实际载体 | 管什么 | 不管什么 | 禁止替代 |
|---|---|---|---|---|
| 角色设定图 | `char_{角色}_ep{xx}_{造型}_turnaround`（无集内变化时用跨集 `char_{角色}_{EP段}_{造型}_turnaround`） | 长相 / 发型 / 妆容 / 服装 / 配饰 | 站位、机位、动作 | `char_*_primary`、`_halfbody`、`_fullbody`、剧照、成片截帧、拼贴板（含表情九宫格 `_expressions`） |
| 场景图 | `scene_{场景}_primary` 或 `scene_{场景}_ep{xx}_{状态}` | 空间结构 / 材质 / 色调 / 本集陈设 | 多朝向的另两面墙 | 名场面合成图、上一集成片截图 |
| 道具图 | `prop_{道具}` / `prop_{道具}_{状态}` | 道具外观与该时点状态 | 谁拿着它 | 用场景图"顺带"承载道具状态 |
| 音色锚点 | `voice_{角色}` → `素材库/01_characters/{角色}/*anchor-voice.wav` | 音色（音频，**不是图片**） | 台词内容、口型 | 把 wav 当图片参考塞进图片位；**缺文件 / 未定稿不许提交** |

> 音色锚点是**角色资产三件套**之一（基准肖像 + 三视图 + wav），在素材阶段与三视图同批次定稿：
> 台词镜必绑 `voice_*`，无台词镜不绑；缺 wav 的角色其台词镜 `BLOCKED`。
> 规格、产出、五项验收与登记见 `drama-production-playbook/references/11-voice-anchor.md`（契约 #23 owner）。

室内跨 ≥2 机位另配 `loc_*`（按朝向引），多人同镜 / 共现另配 `rel_*`：
两者都不在 `episode_spec` 的 refs 里，须按 sidecar 手工追加 `--reference-asset`（`19` §8）。

### 2.2 音色槽位的 provider 分叉（代码事实，别猜）

| 目标 | 后端行为 | 装配纪律 |
|---|---|---|
| `sparkhub-seedance` | `_build_sparkhub_seedance_ref_kwargs` 按素材类型路由：图片 → `image_urls`（**须先过 `seedance_asset_audit`，未审核直接报错**）、视频 → `video_urls`、音频 → `audio_urls`（免审，转公网 URL） | 可以传 wav；图片资产先确认已审核 |
| 直连 `seedance-2-x` | `worker` 把全部参考字节塞进 `reference_image_bytes_list`，provider 逐张当图片编码成 data URL | **音频必须从参考里剥离**，混入会被当图片解码，直接失败或污染参考集 |

- 音色不够像 → 修 prompt 的语气/语速与角色绑定，**不是"多传一个 wav"**。
- 不确定通道是否支持时，先只传图片跑通，再单独验证音频通道；把结论记进 sidecar，别每次重试。

### 2.3 按镜型装配

顺序固定为 **角色 → 场景 → 道具 → 音色**（`SLOT_ORDER`），不要随手换序。

| 镜型 | 必配 | 可选 | 不要 |
|---|---|---|---|
| 单人镜（无对手） | 本集妆造三视图 | 场景 primary / 集内状态图 | 关系帧（没有第二人时引它只会添乱） |
| 双人同镜 / 共享站位正反打 | `rel_*` + 两人的 `*_turnaround` + 场景 | `loc_*` | 只引一人三视图（另一人会被模型自由生成） |
| 室内多机位 / 正反打 | `loc_*` 对应朝向 + 场景 primary | 人物三视图 | 一张 primary 打天下（反打必换墙） |
| 道具特写 | `prop_{道具}_{状态}` | 有手入画时加角色三视图 | 靠文字描述道具状态 |
| 空镜 / 环境 | 场景 primary 或集内状态图 | `loc_*` | 人物三视图 |
| 多人物理接触 / 群像 | `rel_*` 已批准版本 | — | 合并进连拍组（见 §3） |
| 名场面合成 | `icon_ep{xx}_*` + 人物三视图 | 场景状态图 | 用合成图承担身份 |

### 2.4 同集一致性的四条铁律

1. **一集一版本**：同一角色在同一场戏里只引一个 `char_*` 版本。本集有换装/染血/受伤，就整段切到
   `char_*_ep{xx}_{造型}_turnaround`，不要"一半旧版一半新版"。
2. **状态切换点必须切图**：变化发生的那一镜起换锚点；不要用同一张图硬演两套妆造。
3. **同组同版本**：连拍组整组共用一套参考；组内混版 = 把拼接问题请回来（`23` §5）。
4. **时段与光线一致**：夜戏引夜景状态图，不要引日景 primary 再靠文字"改成夜里"。

### 2.5 错引八症 → 先查什么 → 怎么修

| 症状 | 先查 | 修法 |
|---|---|---|
| 第 3 镜换了外套、第 7 镜又换回来 | 两镜引的 `char_*` 版本是否同一个 | 统一版本；同时删掉人物行里的服饰描述 |
| 款式对、污渍换位 | 提示词是否重述了妆造 | 删描述，只留一致性锚句（`21` §5） |
| 床 / 输液架忽有忽无 | 有没有 `scene_*_ep{xx}_{状态}` | 补集内场景状态图 |
| 反打后墙换了、门窗位置变 | 室内跨机位是否只引了一张 primary | 补 `loc_*`，按朝向逐一引 |
| 每镜站位都重排 | `rel_*` 缺，或同组合引了不同版本 | 同一组合复用同一版关系帧 |
| 人脸每镜都像换了人 | 是否引了半身照 / 剧照 / 截帧 / 拼贴板 | 换成 `*_turnaround`（`21` §6） |
| 道具前后不一（信撕了又完好） | 引的是 `prop_*` 还是 `prop_*_{状态}` | 按剧情切状态版 |
| 道具变色 / 变形 / 变成别的物件 | 道具图是否在 refs 内、配色形制有无锚点、是否被序号截断 | 道具图入列 + 锚点写死配色形制，取消关键道具截断（09 §C1） |
| 相邻两组背景对不上 / 串到别的空间 | 后一组是否漏挂场景图、`loc` 是否错标他场、文字是否写了图里没有的陈设 | 每组挂同一 scene primary，loc 对齐实际空间，衔接帧并排核对（09 §B1/B2） |
| 声音串角色 / 台词音色不对 | `@voice_id` 是否绑到正确角色、`voice_manifest` 是否有该角色、`drama assets` 的 `missing_files` 是否有音色、wav 是不是当前集段该用的版本 | 重绑 ID；缺音色回素材阶段补定稿 wav（该角色台词镜可能要整批重出）；多声线高危组拆组（09 §D2、11 §8/§9） |

### 2.6 引用核对（提交前跑一次）

```bash
opendreamina drama assets EPxx --project .   # valid / errors / warnings / 资产计数
opendreamina drama spec EPxx --project .     # 看 shots[].refs 与 assets[].kind
```

执行纪律：只有 `kind == "image"` 的 refs 进图片位；`kind == "audio"` 按 §2.2 分叉处理；
`rel_*` / `loc_*` 不在 spec 里，按 sidecar 追加。**引用解析不出来就不生成**——无参考生成必然前后不一致。

## 3 查三 · 编组粒度（先合后拆）

三问，答完再排任务：

1. **是不是"同一次连续拍摄能拍下来的"？** 同场、同时段、连续动作流 → 合。
2. **配额是否允许？** 单任务 ≤30s（Seedance 2.5），推荐 12–20s，组内 2–4 镜（**首版 2 镜起手**，见下）、单镜 ≥3s；
   非 2.5 模型上限 15s，只能做 2–3 镜小组。先算时长再编组，不要反过来。
3. **有没有必须拆的？** 跨场跨时（C 断接）、多人物理接触与群像、精确咬口型台词特写、
   复杂运镜 / 特效合成点、需精确起幅的镜 → 独立任务。

合并后纪律（最容易在第二步破功）：

- 组内**不得单 roll**；重出粒度是整组，改镜段与切点后整组重生成再重新裁切。
- 母版留 `video_renders/_takes/`，按切点裁成逐镜文件再落各镜目录；裁不动就如实降级。
- 断点恢复按「整组」跳过，不做组内混版。
- **合组不免除** `19` / `20` / `21` 的锚点门禁；跨妆造状态的镜不得同组。
- 组的第一镜仍要对组外上一镜负责：接续句照写（`22` §5.1）。

三种"假合组"要拦：

| 假合组 | 为什么不算 | 正确做法 |
|---|---|---|
| 一个镜头里塞多个动作 | 合并的是"镜头数"，不是动作数 | 组内仍一镜一动作，靠切点分 |
| 为用满 30s 硬加镜头 | 第 3、4 镜人脸与一致性会衰减 | 12–20s 收手，重头戏放前台 |
| 组内每段各自重写外观与场景 | 每段重新采样，接缝必崩 | 全局段只写一次，段内只写变与接续 |

**实测校准（本仓 EP01 开头样片）**：12s 任务排了三段，**只执行了第 1 刀（3.5s），第 2 刀（7.5s）丢失**，
第三句台词落在错误画面上，同时第 2 镜出现脸漂与场景穿帮（万圣节集里出现圣诞花环）。
结论：**首版按 2 镜编组**，跑通、切点数对得上之后，再逐级试 3 镜；
`23` §3 的「2–4 镜」是上限区间，不是起手值。切点丢失优先怀疑镜数过多，而不是继续加提示词。

## 4 提交前 60 秒

- [ ] 提示词模板字段 / 段序 / 标签**逐字**对上，没有自创段与自创标签
- [ ] 时间码之和 = `duration`；单镜时 `duration` = 该镜时长，且**显式传**
- [ ] `frame_mode` 显式为 `reference`（用 `first` 已在 sidecar 写「首帧理由」）
- [ ] 参考都是**本集版本**，同组共用一套，无半身照 / 剧照 / 截帧 / 拼贴板
- [ ] `kind=audio` 的参考按 provider 分叉处理，没混进图片位
- [ ] **每个出声角色**：`anchor-voice.wav` 在位且过五项验收、`voice_manifest` 已登记、台词镜绑了对应 `voice_*`；`drama assets` 的 `missing_files` 无音色项（缺则 `BLOCKED`，见 `11` §4/§6）
- [ ] 组外首镜的英文接续句在 prompt 首部；组内第二镜起不写长入场句
- [ ] 台词逐字、带说话人与语气；无台词镜写了「无对白」并加了 `voiceover, dialogue, narration`
- [ ] 画面无字幕/标题卡/字幕条/屏显文字/水印/logo/签名；台词镜声明「仅人声、不上屏」
- [ ] 跨分组同一场：每组挂同一张 scene primary，`loc` 与实际空间一致；场景文字没写参考图里没有的陈设
- [ ] 出镜道具参考图在 refs 列表内，配色/形制/材质已写死锚点；refs 覆盖核对无截断、无缺图
- [ ] 负面词含画面项（§4.3）与音乐项（§4.5）；独立 `negative_prompt` 若被通道丢弃，负面约束已留在正向文本内
- [ ] `drama assets` valid、`drama lint` errors = 0
- [ ] 三查里没有"以后再补"的项
- 症状对不上时按 `playbook/references/09-common-pitfalls-checklist.md` 索引定位

## 5 违规处置

1. 未过三查的任务**不提交**；已提交才发现问题的，产物保留但标 `RETRY` 并写明是哪一查、哪一项。
2. 同一集因**同类问题**返工 2 次 → 停下来修模板 / 词库 / 锚点，继续抽卡只会把同一错误抽 N 遍。
3. 三查全过仍出现前后不一致 → 交 shot-reviewer 初审判定是"生成问题"还是"分镜本身没设计完"，
   不要在生成层反复试。
