# 04 · 自检评分与迭代

## 1. 交付前自检清单

逐项检查，全部通过才交付：

- [ ] 六工位中**主体、场景、镜头**三个必填工位无空缺。
- [ ] 没有「高级感」「氛围绝了」「很酷」这类不可渲染的形容词。
- [ ] 没有互相冲突的描述（极简 vs 繁复、凝固高速动作 vs 长曝光）。
- [ ] 主体描述前置，风格词不喧宾夺主。
- [ ] 正向与负面提示词内容不重复、不互为反义堆砌。
- [ ] 视频提示词只有一个主要动作、只选一种运镜。
- [ ] `aspect_ratio` / `resolution` / `duration` 与目标模型的 `list_models` 能力一致。
- [ ] 参数使用后端真实字段名（`guidance_scale` 而非 `guidance`）。
- [ ] 未编造用户未提供的叙事信息。
- [ ] 已输出「诊断 + 改动说明」，用户能看懂改了什么、为什么。

## 2. 评分（满分 100）

| 维度 | 分值 | 评分要点 |
| --- | --- | --- |
| 主体明确度 | 20 | 不看原话也能画对主体；外观特征具体 |
| 结构完整度 | 20 | 六工位（视频含运动/运镜）填充合理，无空缺关键项 |
| 具体可渲染度 | 20 | 无空泛形容词；描述可直接映射到视觉元素 |
| 镜头明确度 | 20 | 景别、机位、景深（视频含运镜与动作）明确 |
| 参数一致性 | 20 | 参数在模型能力内；正负词分工正确；字段名正确 |

判定：

| 分数 | 处置 |
| --- | --- |
| ≥ 80 | 交付 |
| 60~79 | 按第 4 节定位短板，补齐后重新自检 |
| < 60 | 判定为「方向不清」，回到诊断四问重新理解需求，必要时向用户确认 |

## 3. 常见问题 → 改词策略

定位到问题后再动手，一次只改 1~2 个变量。

### 3.1 图片

| 症状 | 原因 | 改词策略 |
| --- | --- | --- |
| 主体不明显 / 被背景淹没 | 主体未前置、景深过大 | 主体移到句首；补「主体居中、浅景深虚化背景」 |
| 画面糊、细节差 | 分辨率不足或提示词过长被稀释 | 提升 `resolution`；删掉次要工位，保留核心 30~50 词 |
| 构图不对 | 缺景别与机位 | 明确景别 + 机位 + 焦段（如「中景、低角度、85mm」） |
| 风格跑偏 | 只写抽象风格名 | 补媒介词（胶片/3D 渲染/水墨）与参考流派 |
| 色彩不符 | 未指定色调 | 补色温与配色方案（如「暖调黄昏金 + 青灰阴影」） |
| 人物畸形 | 手部/多人交互复杂 | 负面词追加手部项；改为半身或近景；简化手部动作 |
| 画面出现文字水印 | 未排除 | 负面词追加「文字, 水印, 签名, 边框」 |
| 过于「AI 塑料感」 | 缺少质感描述 | 补「皮肤纹理自然、胶片颗粒、微瑕疵」 |

### 3.2 视频

| 症状 | 原因 | 改词策略 |
| --- | --- | --- |
| 主体形变 / 崩坏 | 一个镜头里动作太多 | 拆成多个任务，每个只保留一个动作 |
| 画面抖动、跳帧 | 运镜过多或动作过剧烈 | 改为「固定机位」；运镜只留一种；负面词加抖动类 |
| 动作僵硬 | 动作描述太笼统 | 写具体幅度与速度（如「缓慢抬手，衣角轻摆」） |
| 与首帧不一致 | 未强调延续性 | 提示词首句写「延续首帧画面与风格」；用 `frame_mode: "first"` |
| 时长内动作做不完 | 动作量与时长不匹配 | 缩短动作或加长 `duration`（须在模型范围内） |
| 背景漂移 | 主体与背景都写得太活跃 | 弱化背景描述，只保留环境特征；负面词加「背景漂移」 |
| 画质不够 | 分辨率档位偏低 | 提升 `resolution`（受模型能力限制） |

## 4. 迭代规则

1. **一次一改**：每轮只改 1~2 个变量，便于定位是哪个改动带来了提升。
2. **先固定 seed**：想比较提示词改动效果时固定 `seed`，排除随机性干扰；确认方向后再放开 seed 抽卡。
3. **先小后大**：先用 `count: 1`（图片）或默认参数验证方向，方向正确再加量或提分辨率。
4. **上限 3 轮**：同一提示词迭代 3 轮仍不理想，说明问题在**方向**而非措辞，应回到诊断四问重新理解需求。
5. **保留好版本**：记录每次改动与对应结果，第 3 轮仍无改善时回退到最佳版本，并换一条思路（换风格、换构图、换模型）。
6. **区分两类失败**：
   - 环境类（未配置 Key、worker 离线、任务卡 pending）→ 修环境，改提示词无效。
   - 内容类（画面不符预期）→ 按第 3 节改词。

## 5. 迭代记录格式

多轮迭代时按下表回报，避免用户来回追问：

| 轮次 | 改动 | 结果 | 下一步 |
| --- | --- | --- | --- |
| 1 | 基线提示词 | 主体正确、色调偏冷 | 补暖色光线描述 |
| 2 | 加「暖色侧逆光」 | 色调改善、构图偏平 | 明确机位为低角度仰拍 |
| 3 | 加「低角度仰拍、浅景深」 | 达到预期 | 交付，放开 seed 加量 |
