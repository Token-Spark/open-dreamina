# 01 · 优化方法论与输出格式

## 1. 核心链路

> **用户意图 → 诊断 → 六工位填充 → 提示词 → 参数 → 任务**

优化不是「把句子写长」，而是**把不可渲染的信息变成可渲染的信息**。

判断标准只有一条：

> 一个没有看过用户原话的模型，能否据此画出用户想要的东西？

## 2. 诊断四问

每次优化前，先回答这四个问题，并显式输出结论。

| 问题 | 检查内容 | 缺失时的处理 |
| --- | --- | --- |
| **主体是什么？** | 谁 / 什么、数量、外观特征、动作或状态 | 必须问用户或给出保守默认（不编造具体人物细节） |
| **在哪、什么时候？** | 场景、环境、时间、天气、氛围 | 按题材补默认场景，并标注「默认，可改」 |
| **怎么看？** | 景别、机位角度、镜头焦段、景深 | 图片按题材给默认镜头；视频必须明确 |
| **什么质感？** | 光线、色调、材质、渲染风格、媒介 | 按题材给默认风格，并标注 |

补充检查（发现即列为问题）：

- **歧义**：一个词有多种视觉解释（如「粉」= 粉色/粉丝、「大」= 特写/尺寸）。
- **冲突**：互相排斥的描述（如「极简」+「繁复细节」、「长曝光」+「凝固高速动作」）。
- **越界**：超出模型能力的参数（时长、分辨率），或 AIGC 不擅长的内容（精确文字、复杂手部交互、多动作连拍）。

## 3. 六工位结构

优化后的正向提示词按以下顺序组织。**只填有信息的工位，不硬凑**。

```text
[1 主体]       主体 + 外观特征 + 动作/状态
[2 场景]       环境 + 地点 + 时间 + 天气
[3 光线]       光位 + 光质 + 色温（如 侧逆光/柔光/黄昏暖调）
[4 镜头]       景别 + 机位 + 焦段/景深（如 中景、低角度、85mm 浅景深）
[5 风格]       艺术风格 / 媒介 / 参考流派（如 电影感、胶片、水墨）
[6 质感]       细节与画质要求（如 皮肤纹理、体积光、高动态范围）
```

视频额外增加两个工位：

```text
[7 运动]       主体动作（唯一主要动作）+ 幅度/速度
[8 运镜]       摄影机运动（推/拉/摇/移/跟/升/降/环绕/固定）
```

> 工位词库与常用取值见 `02-prompt-templates.md`。

## 4. 重写规则

1. **保留用户明确表达**：用户说了「红裙子」，就写「红色连衣裙」，不改色、不改品类。
2. **补位不编事**：补的是镜头、光线、质感等**表现层**信息；不要编造用户未说明的**叙事层**信息（人物身份、剧情、具体品牌）。
3. **一次一改**：如果原提示词已能出图，优先做最小增强（补 1~2 个关键工位），而非全盘重写。
4. **降形容词，升名词**：把「很美」换成可渲染的具象描述（肤质、光比、构图）。
5. **控制长度**：图片提示词建议 30~80 词；视频建议 20~60 词。过长会稀释关键信息，权重被平均。
6. **权重前置**：最重要的主体与风格放句首，模型对开头内容更敏感。
7. **负面词独立**：只写要排除的（畸形、多指、水印、文字、低分辨率等），不要把正向内容取反塞进去。
8. **语言一致**：中英文均可，但同一次任务内保持一致，混合语言易降低理解稳定性。

## 5. 输出格式（强制）

优化完成后，按以下结构输出。用户只要提示词时可省略「参数」以外的执行相关段落。

````markdown
## 诊断
- 缺失：<工位 / 信息>
- 歧义：<词 → 可能的两种解释>
- 冲突：<A 与 B 互斥>

## 优化后 · 正向提示词
<结构化提示词，按六工位组织>

## 优化后 · 负面提示词
<要排除的内容>

## 建议参数
| 参数 | 值 | 说明 |
| --- | --- | --- |
| aspect_ratio | 16:9 | 风景/横版叙事 |
| resolution | 2K | 平衡质量与耗时 |
| guidance_scale | 7 | 默认权重 |

## 改动说明
- <原词> → <新词>：<为什么这样改>

## 自检
- 评分：<0~100>（维度见 04-quality-and-iteration.md）
- 仍不确定项：<需要用户确认的点>
````

## 6. 不确定时的处理

- 信息不足以确定主体时，**先问再写**（一问一答即可，不要连环追问）。
- 用户拒绝补充时，用保守默认并在「改动说明」中标注「默认值，可改」。
- 不要为了显得完整而编造叙事细节——编造的信息会让用户误以为是自己给的。
