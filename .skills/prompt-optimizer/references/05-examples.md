## 示例 1 · 图片：口语化人像

**用户输入**

> 画个在咖啡馆看书的女生，要好看点，有点氛围

### 诊断

- 缺失：镜头（景别/机位）、光线、风格质感
- 歧义：「好看点」→ 指颜值、画质还是构图？按「写实高质量人像」理解
- 冲突：无

### 优化后 · 正向提示词

```text
一位二十多岁的女性坐在靠窗位置低头看书，米色针织衫，发丝自然垂落，
午后咖啡馆，木质桌面、玻璃杯与散落书页，窗外暖阳斜射形成柔和侧光，
中景，略低机位，85mm 镜头浅景深虚化背景，
写实人像摄影，胶片颗粒与暖调，皮肤纹理自然、高动态范围
```

### 优化后 · 负面提示词

```text
低分辨率, 模糊, 噪点, 手指畸形, 五官错位, 皮肤过平滑, 水印, 文字, 塑料感
```

### 建议参数

| 参数 | 值 | 说明 |
| --- | --- | --- |
| aspect_ratio | 3:4 | 人像竖版构图 |
| resolution | 2K | 平衡质量与耗时 |
| guidance_scale | 7 | 默认权重 |
| count | 1 | 先验证方向 |

### 改动说明

- 「好看点」→ 拆成「皮肤纹理自然 + 胶片颗粒 + 暖调 + 浅景深」：把主观评价落地为可渲染特征
- 补「中景 + 略低机位 + 85mm 浅景深」：原描述无镜头信息，模型会自由发挥
- 补「暖阳斜射柔和侧光」：氛围来自光线，而非形容词

### 自检

- 评分：88（主体、结构、具体度、镜头、参数均达标）
- 仍不确定项：是否需要特定发色或服装风格

## 示例 2 · 图片：抽象风格需求

**用户输入**

> 来个赛博朋克的，要高级感

### 诊断

- 缺失：主体（只有风格没有主体）、场景、构图
- 歧义：「高级感」→ 可能是低饱和高级灰，也可能指画质精细，两者方向相反
- 冲突：「赛博朋克」通常高饱和霓虹，「高级感」常指克制低饱和——需向用户确认

> 处理：先问一句「要霓虹浓烈的经典赛博朋克，还是低饱和克制的冷调未来感？」
> 用户选择「低饱和克制」后按下述优化。

### 优化后 · 正向提示词

```text
雨夜中独自行走的机械义体人，黑色长款雨衣，背影视角，
狭窄的未来都市巷道，湿滑地面反射冷蓝与洋红霓虹，
低饱和冷调、强对比，全景，平视机位，35mm 广角大景深，
电影感概念艺术，雾气与体积光，细腻金属质感与雨丝
```

### 优化后 · 负面提示词

```text
高饱和, 廉价霓虹, 低分辨率, 模糊, 畸变, 多余肢体, 水印, 文字, 卡通感
```

### 建议参数

| 参数 | 值 | 说明 |
| --- | --- | --- |
| aspect_ratio | 21:9 | 宽银幕强化电影感 |
| resolution | 2K | — |
| guidance_scale | 8 | 风格化任务适当提高权重 |
| count | 2 | 风格化结果差异大，出 2 张挑选 |

### 改动说明

- 补主体与场景：原描述只有风格，模型无法确定画什么
- 「高级感」→ 「低饱和冷调 + 强对比 + 35mm 大景深 + 细腻金属质感」
- 「赛博朋克」保留并加限定（低饱和），避免与高级感冲突

### 自检

- 评分：85
- 仍不确定项：主体是人物还是纯场景

## 示例 3 · 视频：文生视频（含运镜）

**用户输入**

> 一个人走在雨里的视频，很有感觉，5 秒

### 诊断

- 缺失：运镜、镜头、光线、画质要求
- 歧义：「很有感觉」→ 指凄冷孤独还是浪漫？按「冷调孤独」理解
- 冲突：无

### 优化后 · 正向提示词

```text
一位穿深色风衣的男子独自走在雨夜街道，缓步前行，
湿漉漉的柏油路面反射霓虹光斑，细雨在路灯下形成光带，
冷蓝主调、路灯光斑暖点缀，中景，平视机位，
镜头缓慢跟随主体横移，电影感颗粒，雨丝清晰、动作平稳
```

### 优化后 · 负面提示词

```text
画面抖动, 闪烁跳帧, 主体形变, 动作僵硬, 肢体穿模, 背景漂移, 面部崩坏, 水印
```

### 建议参数

| 参数 | 值 | 说明 |
| --- | --- | --- |
| aspect_ratio | 16:9 | 横版叙事 |
| resolution | 1080p | 视频定稿档位 |
| duration | 5 | 与用户要求一致；Seedance 2.5 支持 4~30 |
| seed | 不指定 | 首轮先看方向 |

> 生成前用 `list_models {mode:"video", model_id:"<model>"}` 核对 `duration` 与 `resolution` 是否在能力内。

### 改动说明

- 补运镜「缓慢跟随主体横移」：视频必须有运镜，否则退化为静帧
- 限定「一个动作」：只保留「缓步前行」，不叠加转头/抬手
- 「很有感觉」→ 「冷蓝主调 + 雨丝光带 + 电影感颗粒」

### 自检

- 评分：86
- 仍不确定项：时长是否需要加长以容纳更多行走画面

## 示例 4 · 视频：图生视频（首帧驱动）

**用户输入**

> 用这张图做一个视频，让画面动起来

**已提供**：`D:/refs/frame.png`（一张傍晚海边人物背影照）

### 诊断

- 缺失：动作、运镜、时长
- 歧义：「动起来」→ 风吹衣物、人物走动、还是纯运镜？按「最小运动」处理最稳
- 冲突：原图已是傍晚逆光剪影，再加强光描述会破坏原图观感

### 优化后 · 正向提示词

```text
延续首帧画面的傍晚海边场景与逆光剪影风格，
人物背影保持静止，海风吹动衣角与发丝轻微摆动，海浪缓缓推进，
暖橙色夕阳侧逆光，中景，固定机位，
镜头极缓慢推近，胶片颗粒，动作自然平缓
```

### 优化后 · 负面提示词

```text
主体形变, 面部崩坏, 肢体穿模, 画面抖动, 闪烁跳帧, 背景漂移, 色彩突变, 过曝
```

### 建议参数

| 参数 | 值 | 说明 |
| --- | --- | --- |
| reference_paths | ["D:/refs/frame.png"] | 工具自动上传并切换为 img2video |
| frame_mode | first | 该图作为首帧 |
| duration | 5 | 仅一个微动作，5 秒足够 |
| resolution | 1080p | — |
| strength | 0.4 | 越低越贴近原图 |

### MCP 调用

```json
{
  "provider": "seedance-2-5",
  "prompt": "<上述正向提示词>",
  "negative_prompt": "<上述负面提示词>",
  "reference_paths": ["D:/refs/frame.png"],
  "frame_mode": "first",
  "duration": 5,
  "resolution": "1080p",
  "strength": 0.4,
  "aspect_ratio": "16:9"
}
```

### 改动说明

- 「动起来」→ 收敛为「衣角发丝微动 + 海浪推进 + 极缓慢推近」：最小运动最不易崩坏
- 首句强调「延续首帧画面与风格」：避免模型重新构图导致与参考图不一致
- 不加新的光线描述：原图已有逆光，重复描述会造成色彩突变

### 自检

- 评分：84
- 仍不确定项：若用户想要人物走动，则需改为动作幅度更大的提示词并延长时长

## 示例 5 · 套用用户已存模板

**场景**：用户说「用我存的那个产品图模板，帮我优化这段话」

### 取模板

```text
list_templates {category: "image"}
→ { name: "极简产品主图", category: "image",
    prompt_text: "<主体>，置于纯净浅灰背景中央，柔和顶光 + 两侧补光，
                  产品摄影，大景深全清晰，细节锐利、无阴影干扰",
    negative_prompt: "杂乱背景, 强烈反光, 阴影过重, 水印, 文字",
    params: { aspect_ratio: "1:1", resolution: "2K" } }
```

### 用户原始输入

> 一个保温杯，商务风

### 套用后 · 正向提示词

```text
哑光深空灰不锈钢保温杯，直立置于纯净浅灰背景中央，杯身无指纹与划痕，
柔和顶光 + 两侧补光，产品摄影，大景深全清晰，细节锐利、无阴影干扰，
商务极简风格，杯盖螺纹与真空层接缝清晰可辨
```

### 优化后 · 负面提示词

```text
杂乱背景, 强烈反光, 阴影过重, 水印, 文字, 指纹, 划痕, 低分辨率
```

### 建议参数

| 参数 | 值 | 说明 |
| --- | --- | --- |
| aspect_ratio | 1:1 | 沿用模板 |
| resolution | 2K | 沿用模板 |
| guidance_scale | 7 | 默认 |

### 改动说明

- 保留模板句式与光线、背景设定，仅替换 `<主体>` 工位
- 「商务风」→ 「哑光深空灰 + 商务极简风格」：把风格词落到材质与配色
- 在模板负面词基础上追加「指纹, 划痕」：产品图特有瑕疵

### 自检

- 评分：90
- 仍不确定项：是否需要指定杯身 Logo 位置（涉及精确文字，AIGC 易失败，建议后期加）
