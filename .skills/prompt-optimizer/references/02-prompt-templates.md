# 02 · 提示词模板与词库

## 1. 模板来源与优先级

优化时按以下顺序取模板（前两者都是「脚手架」，用于定位该填哪些工位）：

1. **用户已存模板**：调用 MCP 工具 `list_templates {category}` 获取（`category` = `image` / `video`）。
   返回字段：`name`、`prompt_text`、`negative_prompt`、`params`。
2. **内置模板**：本文件的第 2、3 节。
3. **无模板**：仍按 `01-optimization-framework.md` 的六工位结构直接写。

套用用户模板的规则：

- 保留模板的**句式结构与风格基调**，只替换主体、场景等可变工位。
- 模板自带的 `params` 作为**默认参数**；与模型能力冲突时以 `list_models` 为准并说明。
- 模板已有 `negative_prompt` 时，在其基础上追加，不整体替换。
- 用户未指定模板时，不要臆造模板名；可直接说明「未使用模板，按内置结构优化」。

> **模板即契约（硬）**：模板的**标签名、行序、段序、固定句式**是不可动的契约层，
> 只有"值"可写。禁止为了"更清楚"改标签（`音效设计`→`声音设计`）、合并/拆分行、
> 重排段序、自创字段、在锚点句上加补语。用户定稿过的模板（§3.4 / §3.5 / 短剧 14 行 /
> 编译 8 段）改动须用户明确批准并记入 sidecar。逐字遵循的判据、七种破坏型"优化"
> 与提交前点名清单见 `production-orchestrator/references/10-generation-preflight.md` §1。

## 2. 图片提示词模板

### 2.1 通用写实（人像 / 产品 / 场景）

```text
[主体与特征] , [动作/状态] , [场景与环境] , [光线] , [景别与机位] , [镜头与景深] ,
[风格与媒介] , [画质与细节]
```

示例：

```text
一位穿米白色针织衫的年轻女性，侧身站在落地窗前，城市黄昏天际线在身后虚化，
暖色侧逆光勾出轮廓光，中景，略低机位，85mm 镜头浅景深，
电影感人像摄影，柔和色调，皮肤纹理自然、高动态范围
```

### 2.2 风格化插画 / 概念设计

```text
[主体] , [场景] , [色彩方案] , [艺术风格/流派] , [笔触与质感] , [构图]
```

示例：

```text
漂浮在云海上的中式石塔，晨雾与朝霞，青绿与暖金对撞配色，
东方水墨与赛博朋克融合概念艺术，细腻笔触与体积光，
对称构图，远处层叠山峦
```

| 机位 | 平视 / 低角度仰拍 / 高角度俯拍 / 过肩 / 顶拍 / 航拍 |

| 光质 | 硬光（强对比）/ 柔光（漫射）/ 体积光（丁达尔）/ 窗口自然光 |

## 3. 视频提示词模板

视频提示词 = **画面描述（同图片） + 运动（主体动作 + 摄影机运动）**。

```text
[主体与特征] , [唯一主要动作] , [场景与环境] , [光线] ,
[景别与机位] , [运镜方式] , [风格与画质]
```

### 3.1 运镜词库

| 运镜 | 写法 | 适用 |
| --- | --- | --- |
| 固定 | 固定机位，画面静止 | 稳定展示、对白 |
| 推 | 缓慢推近（dolly in） | 聚焦情绪、揭示细节 |
| 拉 | 缓慢拉远（dolly out） | 交代环境、收尾 |
| 摇 | 水平摇镜（pan）/ 垂直摇镜（tilt） | 扫视环境 |
| 移 | 横向平移（truck）/ 前移跟拍 | 跟随主体 |
| 跟 | 跟随主体移动（tracking） | 行走、运动 |
| 升 / 降 | 升镜 / 降镜（crane） | 揭示规模、宏大感 |
| 环绕 | 绕主体环绕（orbit） | 展示立体感、仪式感 |

### 3.2 示例

```text
一位穿深色风衣的男子，缓缓抬头望向雨夜的霓虹招牌，湿漉漉的街道反射彩色光斑，
冷蓝与洋红混光，近景，平视机位，缓慢推近，电影感颗粒，雨丝清晰
```

默认按全能参考写（提交时 `frame_mode` **显式传 `"reference"`**，不传没有可靠默认值）：
画面描述与运动照常写，参考图负责身份 / 空间 / 场景。
只有确需「从这张图精确起幅」（或平台不支持 `reference`）时才用 `frame_mode: "first"`，
此时把画面描述简化为「延续首帧风格 + 动作 + 运镜」，并写明用首帧的理由。

### 3.3 视频专项约束

- **一个镜头一个动作**：要「先走路再转身」就写进连拍组的两个镜段（§3.5），不要塞进一个镜头。
- **动作要可渲染**：写「衣角轻微摆动」「发丝被风吹起」，不写「内心复杂情绪闪过」。
- **运镜只选一种**：同时推 + 摇 + 环绕会让画面崩坏。
- **时长匹配内容**：5 秒只够一个动作；10 秒可容纳一个动作 + 一段运镜；
  **多镜头连续戏走连拍组**（§3.5），总长可到 30 秒（Seedance 2.5），不要拆成多个 5 秒任务各猜一次站位。
- **接续先写一句**：有前序镜头时，提示词首句是接续句
  （`Continuing directly from the previous shot: {位置关系}，{动作在第几拍}，{表情余势}；{光源方位} stays the same.`），
  只写状态、不写上一镜的动作、不写服饰；模板与正反例见
  `ai-video-director/references/22-shot-continuity-in-generation.md` §5.1。独立单镜不写，
  也不要用首帧去替代这一句。

### 3.4 短剧镜头提示词标准模板（用户定稿 · 唯一版本）

> 短剧管线内每个镜头一律按本模板写：一行一个工位，行序不动。
> `//` 之后是工位说明，不是内容——写进提示词前删掉。

```text
镜头功能：全景，固定镜头 //镜头功能 + 镜头运动
人物：Leah(@//char_id/，@//voice_id/)
场景描述：场景 scene_id（@//primary_id/），道具(@//prop_id/)
秒级动作拆解:
-[0-1s]Leah 坐在门外，低头看着手机，安静又忧郁
台词同步
-[0-1s]Leah(焦虑地，语速每秒 4 个词)"Hey GPT, how could I get a boy friend before Christmas eve?"
音效设计：无背景音乐；
基础环境音：必须实填
画面风格：90 年代美国电视剧剧照质感，VHS 录像带胶片颗粒，轻微偏色，柔焦
特效音：无则写「无」
```

九行工位，顺序不可变：镜头功能 → 人物 → 场景描述（含道具）→ 秒级动作拆解 →
台词同步 → 音效设计 → 基础环境音 → 画面风格 → 特效音。

填写口径：

1. **镜头功能**写「景别 + 镜头运动」，如「全景，固定镜头」「中景，缓慢推近」。
   景别取 `wide/medium/close_up/extreme_close_up/full` 对应的中文档位，运镜取分镜枚举里的同义写法
   （固定 / 推 / 拉 / 摇 / 移 / 跟 / 升降）。**一个镜头只写一种运镜**。
2. **人物**写 `Name(@角色素材，@音色素材)`。`@//char_id/`、`@//voice_id/` 是**文档占位符**：
   实际输入框插入的是 `@{素材名}` 形式的 @ 引用 token（前端 `promptMention`），
   不要把 `//char_id/` 原样粘进提示词。妆造一经图片锁定，这一行只写身份项 + 本镜动作，
   **不写服饰 / 发型 / 妆容**（见 `drama-prompt-pattern.md`「集内妆造锁定」）。
   无台词镜注「不出对白、不绑口型」；不入画角色标注「不入画」。
3. **场景描述**一行写两件事：场景 + 道具。场景锚点用素材名引用（`@//primary_id/` 同为占位符）；
   无道具写「无」。陈设已由集内状态图锁定时，只写「延续参考图陈设」，不重述床 / 输液架 / 药碗。
4. **秒级动作拆解**按秒实填，覆盖镜头完整时长、不留空档，**一镜一个主动作**；
   复杂动作拆镜或进连拍组（§3.5）。表情写在动作句尾（「低头看着手机，安静又忧郁」），
   不单开一行、不写心理活动。
5. **台词同步**逐字写台词 + 说话人 + 情绪 + 语速；台词原文加引号，**不得改写**。
   台词必须在**生成期同期出声**（模型同一次生成里出声并咬口型）；后期只铺 BGM、混音、烧字幕，
   **不做 TTS 配音、不做口型重对**。没出声 / 台词错字 / 口型不对 → 改提示词或换支持同步音频的模型重出。
   无台词镜写「无」，并在负面词排除 `voiceover, dialogue, narration`（§4.5）。
6. **音效设计**恒为「无背景音乐」，并补一句：无垫乐、无旋律线、无节奏鼓床；
   配乐只在后期轨标注，不进生成提示。
7. **基础环境音必须实填**：声源 + 电平（如「暖灯嗡鸣，低频」「门缝夜风，弱」）。
   **动作触发音（呼吸 / 衣物 / 脚步 / 餐具 / 物体接触）写在这一行**，按秒段交代，不另起行。
   禁用 `faint ambient sound`、`ambience`、`pad`、`score` 这类能被模型扩成配乐的模糊词。
8. **画面风格**填全局风格常量逐字（`AESTHETIC` + `MEDIUM`）。逐镜都写，但**值必须一致**——
   改风格只改 `tools/assets_manifest.json` 的 `style` 一处。
   用 `drama compile --with-style` 时这行**不再重复写**（编译器已在尾部追加，写两遍等于双份常量）。
9. **特效音**无则写「无」；有也仅限动作触发，不做情绪煽动音效。

> 一句话口径：**画面工位归 §3 与编译 8 段，声音与风格归这九行**。九行里的
> 音效设计 / 基础环境音 / 画面风格 / 特效音 编译时不进 8 段，由执行层按 AUDIO 段与风格常量追加。
> 编译成英文时，禁乐规则**前置为 AUDIO 段**（权重高于句尾否定），音乐排除同时进 `negative_prompt`（§4.5）——
> 不依赖参数开关，`generate_audio` 只控制整条音轨有无，不能选择性禁乐。

#### 3.4.2 与 `shots.md` 的对应（别把模板当分镜表）

本模板是**提示词侧**写法。落进 `shots.md` 时字段要拆到对应行与列，不能整段照搬——
`drama lint` 的 `REQUIRED_BLOCK_LINES` 硬编码了必填行，总览表固定 15 列：

| 模板工位 | 落 `shots.md` 的位置 | 进编译 8 段 |
|---|---|---|
| 镜头功能 | `**镜头功能：**` 写**戏剧功能**（对话/反应/建立/POV/反转/插入）＋固定或运镜；景别、机位、运镜另写总览表三列 | ① 摄影语言（取自总览表，不取本行） |
| 人物 | `**人物：**` + `**资产绑定：**` 的角色与音色 | ② 角色锚点、⑥ 不入画角色 |
| 场景描述＋道具 | `**场景描述：**` + `**资产绑定：**` 的场景与道具 | ④ 场景锚点 |
| 秒级动作拆解 | `**秒级动作拆解：**` + 总览表 动作/表情列 | ③ 动作＋表情 |
| 台词同步 | `**台词同步：**` + 总览表 台词列 | ⑤ 台词 |
| 音效设计 / 基础环境音 / 特效音 | 分镜侧同样三行（`**动作触发音：**` 已并入基础环境音，不再必填） | 不进编译，执行层按 AUDIO 段追加 |
| 画面风格 | **不进 `shots.md`**——它是全局风格常量，存在 `tools/assets_manifest.json` 的 `style` | ⑧ 之后由 `--with-style` 追加 |

必须记住的差异只剩两条：

- `**镜头功能：**` 这一行**不能**写「全景，固定镜头」。解析器取这一行原文判 POV / 对白等类型
  （`shots_lint` 用 `function_zh` 找「POV / 主观 / 第一视角」），写成景别会让 POV 检出失效、
  审片卡的镜头功能也变错。景别与运镜在 `shots.md` 里归总览表。
- **画面风格不进分镜表**。它是 `manifest.style` 的全局常量，40 集共享一处；写进每镜只会变成
  第二份事实，改风格时对不上。

> 声音行两侧已经对齐：分镜表与提示词模板都是三行（音效设计 / 基础环境音 / 特效音）。
> 老分镜里若仍单列 `**动作触发音：**`，`drama lint` 只出迁移 warning（`LEGACY_BLOCK_LINES`），不再判错。

### 3.5 多镜连拍组模板（一次生成多个镜头）

> 适用：同一场、同一时段的连续镜头（动作接动作 / 正反打 / 跟拍 / 同场换机位 / 空镜序列）。
> 单任务总长 ≤30s（Seedance 2.5），组内 2–4 镜、单镜 ≥3s。判据见
> `ai-video-director/references/23-take-group-multi-shot.md` §2/§3。

```text
<全局段（只写一次）> 风格常量 + 场景锚点 + 人物身份（@char_id，不写服饰）+ 音轨纪律
<接续句（仅第一镜）> Continuing directly from the previous shot: {位置关系}, {动作在第几拍}, {表情余势}; {光源方位} stays the same.
Shot 1 (0.0-6.0s) — {景别}, {机位}, {运镜}：{一个动作}。{台词 / No dialogue}
HARD CUT
Shot 2 (6.0-13.0s) — {景别}, {机位}, {运镜}：{同一空间与光向的短交代}, {动作从第几拍接着走}。{台词 / No dialogue}
HARD CUT
Shot 3 (13.0-20.0s) — {景别}, {机位}, {运镜}：{一个动作}。{台词 / No dialogue}
<尾段（只写一次）> 负面词（§4.3 + §4.5）+ 音轨约束
```

四条硬写法：

1. **全局段只出现一次**。每段重复"黑发、白裙、锻炉内景"→ 每段重新采样外观，接缝处必崩。
2. **每段必须带秒时间码**，切点行独占写 `HARD CUT` / `CUT TO`。`then` / `next` 会被理解成连续运动，糊成一条长镜头。
3. **第二镜起不写完整入场句**，只写一句短语（`same room, key light still from frame left`）；
   长篇重述反而诱发状态重置。动作写"到哪一拍"（`the knife already past her shoulder, she drives it down`），
   不写"她举起刀"（重演）。
4. **时间码之和 = `duration`**。不等时模型按比例拉伸，切点全部漂移。

参数：`duration` = 时间码之和（显式传）；`frame_mode: "reference"`；整组共用一套同版本参考；
轮询按 ≥1200s 放宽。母版产出后须按切点裁成逐镜文件（ffmpeg 见 `23` §7）。

不适用的情形仍走单镜模板 §3.1–3.4：跨场跨时（C 断接）、多人物理接触与群像、
精确咬口型的台词特写、复杂运镜 / 特效合成点、需精确起幅的镜。

## 4. 负面提示词库

按模式取用，避免与正向提示词重复。

### 4.1 图片通用

```text
低分辨率, 模糊, 噪点, 过曝, 欠曝, 畸变, 多余肢体, 手指畸形, 五官错位,
水印, 文字, 签名, 边框, 低质量, 塑料感
```

### 4.2 人像追加

```text
脸部扭曲, 皮肤过平滑, 眼睛不对称, 牙齿畸形, 六指, 肢体粘连
```

### 4.3 视频追加

```text
画面抖动, 闪烁跳帧, 主体形变, 动作僵硬, 肢体穿模, 背景漂移, 面部崩坏,
镜头抖动, 画面撕裂, 对白字幕, 台词字幕, 标题卡, 字幕条, 屏幕文字, 文字水印,
no subtitles, no captions, no on-screen text, no text overlay, no title card, no watermark, no logo, no signature
```

> 生成期口径：人物台词只走人声与口型，**不上屏**；字幕、标题卡、屏显文字一律后期才加。
> 若所用通道的独立负面词字段被 provider 丢弃（不写入上游 payload），上述禁令必须同时留在正向 prompt 文本内，不能只交负面参数。
