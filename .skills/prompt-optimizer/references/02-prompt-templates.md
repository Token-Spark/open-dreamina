# 02 · 提示词模板与词库

## 1. 模板来源与优先级

优化时按以下顺序取模板（前两者都是「脚手架」，用于定位该填哪些工位）：

1. **用户已存模板**：调用 MCP 工具 `list_templates {category}` 获取（`category` = `image` / `video`）。
   返回字段：`name`、`prompt_text`、`negative_prompt`、`params`。
2. **内置模板**：本文件的第 2、3 节。
3. **无模板**：仍按 `01-optimization-framework.md` 的六工位结构直接写。

套用用户模板的规则：

- 保留模板的**句式结构与风格基调**，只替换主体、场景等可变工位。
- 模板自带的 `params` 作为**默认参数**；与模型能力冲突时以 `list_models` 为准并说明。
- 模板已有 `negative_prompt` 时，在其基础上追加，不整体替换。
- 用户未指定模板时，不要臆造模板名；可直接说明「未使用模板，按内置结构优化」。

## 2. 图片提示词模板

### 2.1 通用写实（人像 / 产品 / 场景）

```text
[主体与特征] , [动作/状态] , [场景与环境] , [光线] , [景别与机位] , [镜头与景深] ,
[风格与媒介] , [画质与细节]
```

示例：

```text
一位穿米白色针织衫的年轻女性，侧身站在落地窗前，城市黄昏天际线在身后虚化，
暖色侧逆光勾出轮廓光，中景，略低机位，85mm 镜头浅景深，
电影感人像摄影，柔和色调，皮肤纹理自然、高动态范围
```

### 2.2 风格化插画 / 概念设计

```text
[主体] , [场景] , [色彩方案] , [艺术风格/流派] , [笔触与质感] , [构图]
```

示例：

```text
漂浮在云海上的中式石塔，晨雾与朝霞，青绿与暖金对撞配色，
东方水墨与赛博朋克融合概念艺术，细腻笔触与体积光，
对称构图，远处层叠山峦
```

| 工位 | 常用取值 |
| --- | --- |
| 景别 | 特写 / 近景 / 中景 / 全景 / 远景 / 微距 |
| 机位 | 平视 / 低角度仰拍 / 高角度俯拍 / 过肩 / 顶拍 / 航拍 |
| 镜头 | 24mm 广角（空间感）/ 50mm 标准 / 85mm 人像压缩 / 135mm 长焦 / 微距 |
| 景深 | 浅景深虚化背景 / 大景深全清晰 |
| 光位 | 顺光 / 侧光 / 侧逆光 / 逆光 / 顶光 / 伦勃朗光 / 蝴蝶光 |
| 光质 | 硬光（强对比）/ 柔光（漫射）/ 体积光（丁达尔）/ 窗口自然光 |
| 色温 | 冷调 / 暖调 / 黄昏金 / 蓝调时刻 / 霓虹混光 |
| 风格 | 电影感 / 胶片颗粒 / 莫兰迪色 / 赛博朋克 / 蒸汽波 / 国风水墨 / 3D 渲染 / 皮克斯风格 / 粘土定格 |
| 质感 | 皮肤纹理 / 布料纤维 / 金属反光 / 玻璃折射 / 体积光 / 高动态范围 / 8K 细节 |

## 3. 视频提示词模板

视频提示词 = **画面描述（同图片） + 运动（主体动作 + 摄影机运动）**。

```text
[主体与特征] , [唯一主要动作] , [场景与环境] , [光线] ,
[景别与机位] , [运镜方式] , [风格与画质]
```

### 3.1 运镜词库

| 运镜 | 写法 | 适用 |
| --- | --- | --- |
| 固定 | 固定机位，画面静止 | 稳定展示、对白 |
| 推 | 缓慢推近（dolly in） | 聚焦情绪、揭示细节 |
| 拉 | 缓慢拉远（dolly out） | 交代环境、收尾 |
| 摇 | 水平摇镜（pan）/ 垂直摇镜（tilt） | 扫视环境 |
| 移 | 横向平移（truck）/ 前移跟拍 | 跟随主体 |
| 跟 | 跟随主体移动（tracking） | 行走、运动 |
| 升 / 降 | 升镜 / 降镜（crane） | 揭示规模、宏大感 |
| 环绕 | 绕主体环绕（orbit） | 展示立体感、仪式感 |

### 3.2 示例

```text
一位穿深色风衣的男子，缓缓抬头望向雨夜的霓虹招牌，湿漉漉的街道反射彩色光斑，
冷蓝与洋红混光，近景，平视机位，缓慢推近，电影感颗粒，雨丝清晰
```

默认走全能参考（`frame_mode: "reference"`）：画面描述与运动照常写，参考图负责身份 / 空间 / 场景。
只有确需「从这张图精确起幅」（或平台不支持 `reference`）时才用 `frame_mode: "first"`，
此时把画面描述简化为「延续首帧风格 + 动作 + 运镜」，并写明用首帧的理由。

### 3.3 视频专项约束

- **一个镜头一个动作**：要「先走路再转身」就拆成两个任务。
- **动作要可渲染**：写「衣角轻微摆动」「发丝被风吹起」，不写「内心复杂情绪闪过」。
- **运镜只选一种**：同时推 + 摇 + 环绕会让画面崩坏。
- **时长匹配动作**：5 秒只够一个动作；10 秒可容纳一个动作 + 一段运镜。

### 3.4 短剧镜头音轨固定结构（用户定稿模板，短剧管线每条镜头必带）

> 画面与运动走 §3；**音轨按下表逐行填写**，不得省略四行声音工位。生成轨＝人声（仅台词镜）＋基础环境音＋动作触发音；原创 BGM 只进后期轨、不写入生成提示。

```text
镜头功能：<戏剧功能> + <镜头运动>
人物：<Name>(@<char_id>，@<voice_id>)；无台词/验证片须显式注明「不出对白、不绑口型」
场景描述:场景 <scene_id>（ref primary_id=<场景基准帧/结构图 id；未批准则写「待批、暂缺」，不臆造>），道具 <prop_id；无则写无>
秒级动作拆解:
-[0-1s]<可见动作/视线/肩线，按秒实填；一镜一个主动作>
台词同步
-[起-止s]<Name>(<情绪/力度>) "<逐字台词>"；无台词镜写「无」
音效设计：无背景音乐；
基础环境音：<必须实填：声源 + 电平，禁止写「无」或用模糊 ambience 替代>
动作触发音：<必须实填：绑定到具体秒段与动作，如呼吸/衣物/餐具/脚步>
特效音：无则写「无」
```

填写口径：

- **台词必须在生成期同期出声**：`台词同步` 行逐字写台词 + 说话人 + 语气 / 语速，由模型在同一次生成里
  产出人声与口型；后期只铺 BGM、混音、烧字幕，**不做 TTS 配音、不做口型重对**。台词错字 / 没出声 /
  口型对不上 → 改 prompt 或换支持同步音频的模型重出，不得后期补。无台词镜写「无」，并在负面词排除
  `voiceover, dialogue, narration`（§4.5）。
- **音效设计恒为「无背景音乐」**，并补一句：无垫乐、无旋律线、无节奏鼓床、无钢琴/弦乐/合成器氛围垫；配乐仅在后期轨标注，不进生成 prompt。
- **禁止整体静音 ≠ 允许配乐**：人声（台词镜）、基础环境音、动作触发音必须保留；但生成期同样不得出现任何背景音乐（细则见 `drama-production-playbook/references/03-seedance-best-practices.md` §6）。
- **基础环境音 / 动作触发音必须具体可辨**（声源、秒段、电平方向）；禁用 `faint ambient sound`、`music bed`、`pad`、`score` 这类可被模型扩成配乐的模糊词。
- 运镜只选一种并忠于分镜；验证片不自创推/拉/环绕。
- 人物 `@char_id`、音色 `@voice_id` 取自资产 ID 总表与已生成音色库；换装即换 char_id
  （集内换妆造 = 换 `*_ep{xx}_{造型}_turnaround`）；临时测试脸须标注「不锁定」。
- **妆造锁定时人物行不写服饰**：char_id 指本集妆造三视图，服装 / 妆容 / 污渍交给参考图，
  提示词只写身份项 + 本镜动作（细则见 `drama-prompt-pattern.md`「集内妆造锁定」）。
- 编译为英文生成 prompt 时：音轨规则**前置为 AUDIO 段**（权重高于句尾否定），音乐排除同时进 `negative_prompt`（§4.5），不依赖参数开关（工具无静音开关）。

## 4. 负面提示词库

按模式取用，避免与正向提示词重复。

### 4.1 图片通用

```text
低分辨率, 模糊, 噪点, 过曝, 欠曝, 畸变, 多余肢体, 手指畸形, 五官错位,
水印, 文字, 签名, 边框, 低质量, 塑料感
```

### 4.2 人像追加

```text
脸部扭曲, 皮肤过平滑, 眼睛不对称, 牙齿畸形, 六指, 肢体粘连
```

### 4.3 视频追加

```text
画面抖动, 闪烁跳帧, 主体形变, 动作僵硬, 肢体穿模, 背景漂移, 面部崩坏,
镜头抖动, 画面撕裂
```

### 4.4 风格化追加（写实任务慎用）

```text
卡通感, 3D 渲染感, 插画感
```

### 4.5 视频负面 · 音乐与音轨禁用（短剧必带，随 negative_prompt 提交）

```text
background music, soundtrack, instrumental score, orchestral score, piano, strings, violin,
synth, ambient pad, ambient music bed, lo-fi, beat, drums, rhythm track, melody, chords, jingle,
cinematic underscore, dramatic swell, stinger
```

口径：

- 台词镜不要把对白本身写进负面；无台词镜 / 验证片再追加 `voiceover, dialogue, narration`。
- 音乐类排除必须与 §3.4 正向 AUDIO 段**双通道同时提交**：正向前置禁乐、负向点名乐种；单写句尾 "no music" 约束力不足。
- 画面类视频负面沿用 §4.3（抖动/闪烁/形变/手部畸形/未授权运镜等），与本节音乐词合并后总量控制在可接受范围，超长时优先删弱相关画面词、不删音乐禁用词。

> 负面词不是越多越好：堆到 60 词以上会干扰采样。一般 8~15 个词足够，只保留真正要排除的；音乐禁用词为短剧硬底线，不计入可删减项。
