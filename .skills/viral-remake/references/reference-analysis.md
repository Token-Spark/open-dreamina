# 参考视频精读方法

目标：在不依赖重型 ASR/视觉模型服务的前提下，让 Agent 对一个爆款视频建立"全片理解"。全部工具为本机 ffmpeg/ffprobe（零 API 成本），缺失时按降级路径执行。

## 1. 证据采集工具箱

| 动作 | 命令（ffmpeg/ffprobe） | 用途 |
|---|---|---|
| 技术元数据 | `ffprobe -v error -show_format -show_streams -of json source.mp4` | 时长/画幅/帧率/音轨，写入档案头部 |
| 定点抽帧 | `ffmpeg -ss <t> -i source.mp4 -frames:v 1 evidence/{t}_{说明}.png` | 关键证据帧（命名含时间码，可回指） |
| 开头密集采样 | `ffmpeg -i source.mp4 -vf "select='lt(t,3)*isnan(prev_selected_t)+gte(t,prev_selected_t+0.4)',showinfo" -vsync vfr evidence/hook_%02d.png` | 钩子段逐 0.4s 细读 |
| 镜头边界 | `ffmpeg -i source.mp4 -vf "select='gt(scene,0.3)',showinfo" -vsync vfr -f null - 2>&1` | scene 切换点时间码列表（粗切分） |
| 静音分段 | `ffmpeg -i source.mp4 -af "silencedetect=noise=-30dB:d=0.35" -f null - 2>&1` | 语流边界（口播视频≈句子边界） |
| 帧网格 | 抽帧后 `ffmpeg -pattern_type glob -i 'f_*.png' -filter_complex tile=4x5 grid.png` | 一张网格总览，肉眼级理解节奏 |

> Windows 注意：`-pattern_type glob` 在部分构建不可用，改用 concat 列表文件或逐帧 `tile` 输入。

**段界取法**：优先取「镜头切换点 ∩ 静音边界」的重合处；重合不上时以静音边界为准（口播视频的叙事单位是句子，不是镜头）。

## 2. 转录的三级降级

| 级别 | 来源 | 锚定能力 |
|---|---|---|
| L1 | 用户提供转录（含时间码更佳）/ 授权 ASR 结果 | 词级锚定（理想） |
| L2 | 用户粘贴纯文案，Agent 对照静音分段对齐句界 | 句级锚定（够用） |
| L3 | 无转录：仅静音分段 + 画面证据解读 | 段锚定 + **生产侧补偿**（见下） |

**生产侧补偿**（L3 的关键）：翻拍的台词是新生成的（STEP 6），配音用即梦 TTS **逐句生成**——每句音频的时长天然精确已知，字幕、切镜、B-roll 进出全部锚到这些句时长上。因此**成片的锚定精度不依赖参考视频的转录精度**；参考侧降级只影响"分析"的颗粒度，不影响"复刻"的执行力。在 TREATMENT 中注明降级级别。

## 3. 词标记帧网格（transcript-linked grid）

有 L1/L2 转录时的杀手锏：把时间轴按句切开，每句抽首帧，在网格图上为每帧标注对应台词（Pillow 写字或文件名承载），得到「**画面变化 ↔ 词语推进**」的对照表。

用法：横向扫读网格，问两个问题：
1. 画面在哪**几个词**上发生了切换？（→ 镜头语言的锚点）
2. 哪些画面与词语**不同步**（说到 A 给 B 画面）？（→ B-roll/悬念手法）

结论写入 TIMELINE.md 的事件列，附帧文件名作证据。

## 4. ANALYSIS.md 写法

三段式，每条观察标注 `[证据 t=xx.x / evidence/xx.png]` 或 `[解读]`：

```markdown
## 钩子（0–3s）
- [证据 t=0.5] 开场即人物面部大特写 + 大字标题"千万别XXX"
- [解读] 钩子机制 = 恐惧诉求 + 信息差（"别"字制造禁止感）

## 论证结构
- [证据 t=3–12] 抛出问题 → 后果放大（B-roll 数据图）
- [证据 t=12–30] 三步方法，每步一个镜头一个字幕卡
- [证据 t=30–45] 反转（"但是"）→ CTA
- [解读] 情绪曲线：紧张→缓解→再紧张→行动，两段式钩子复现

## 系统分工
| 系统 | 功能 | [证据] |
|---|---|---|
| A-roll | 主体口播，中近景，单机位 | t=0.5/6/15 |
| B-roll | 数据/后果可视化，每 8s 一条 | t=8/24 |
| Caption | 逐句大字幕，关键词变色 | t=3 起 |
| Typography | 仅钩子与 CTA 出花字 | t=0.5/43 |
| MG | 无 | — |
| Effects | 切镜硬切为主，爆点处闪白 | t=30 |
| Sound | 口播 + 爆点处音效，无 BGM | — |
```

## 5. TIMELINE.md 写法

段落表 + 事件绑定，示例：

```markdown
| # | 时间码 | 台词锚 | 事件 | 功能 | 系统 |
|---|---|---|---|---|---|
| 1 | 0.0–0.5 | （无） | 大特写进 + 花字标题 | 钩子·视觉 | A-roll/Typography |
| 2 | 0.5–3.0 | "千万别再XXX了" | 字幕逐句上 | 钩子·语言 | Caption |
| 3 | 3.0–5.5 | "我今天告诉你三个方法" | 硬切中景 + 句末切 B-roll 预告 | 承诺 | A-roll/Caption |
```

要求：
- 段落连续覆盖全片，不留空档
- 「台词锚」列在 L3 降级时填段功能描述
- 事件只写可验证的（帧/波形可指），不写"感觉节奏很快"这类不可执行描述——节奏快慢翻译成事件密度：`[证据] 0–12s 内 6 次镜头切换，平均 2s/切`
