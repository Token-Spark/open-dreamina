# 剧目定制规范（Drama Review Brief）

> 对应 SKILL.md 索引中的 `references/03-drama-brief.md`。
> 每次审片必加载。包含：review_brief.md 的查找约定、Schema、与通用规则的合并规则、生成与示例。

## 1. 为什么需要剧目定制

通用规则（02）保证「每一镜都按同一把尺子量」；但每部剧的制作要求不同——画幅、质感、角色锚点、平台合规、重点镜头都不一样。**剧目审片规范（review_brief.md）就是那把「这部剧自己的尺子」**：它不改写通用规则的结构，只定制权重、追加检查项、收紧阈值、补充红线。

> brief 与 shots.md 的分工：shots.md 是**分镜层**（每一镜应该是什么，后端已自动解析为条目元数据）；review_brief.md 是**剧目层**（这部剧整体怎么审）。brief 里的全局内容（风格基准、角色锚点）常与 shots.md 的「全局风格常量」「资产绑定」同源——brief 只需引用或摘录，不必复制全文。

## 2. 文件约定与查找顺序

按以下顺序查找剧目定制规范，命中即停：

1. **用户显式指定**：对话中给出的路径或直接粘贴的要求（优先级最高；粘贴的口语要求先按模板整理成 brief 再继续）。
2. **审片对象目录**：`<审片根目录>/review_brief.md`（审片中心会话的 root_path 对应的宿主机目录；离线模式即用户给的目录）。
3. **剧集根目录**：与 `shots.md` 同级或其上一级目录中的 `review_brief.md`（多集剧通常放剧集根，与 `00_分镜总索引.md` 同级）。
4. **都没有** → 纯通用规则审片（强制规则 8：汇总报告注明「未加载剧目定制规范」）。

约定：

* 文件名固定 `review_brief.md`，UTF-8，Markdown。
* brief 是**审片规范**，不是创作文档——只写「怎么审」，不写「怎么拍」。
* brief 有版本头（版本/日期/维护人）；审片报告必须记录所用 brief 的版本。
* brief 可以由本技能代为生成（见第 5 节），但**生成后必须请用户确认**再作为审片依据。

## 3. Brief Schema（八段式）

模板见 `assets/review-brief-template.md`。各段均可省略，省略 = 沿用通用默认：

```markdown
# 《剧名》审片规范（Review Brief）
> 版本：v1 ｜ 更新：YYYY-MM-DD ｜ 维护人：—

## 1. 剧目概况
剧名 / 题材 / 集数 × 单集时长 / 目标平台 / 目标观众 /
画幅与分辨率（如 9:16，1080×1920）/ 帧率 / 对白语言 / 字幕与 BGM 要求

## 2. 视觉风格基准
整体风格关键词 / 色调 / 光感 / 质感（如「90 年代电视剧，柔光胶片颗粒」）/
参考图相对路径（角色设定图、场景图、风格板）

## 3. 角色外观锚点
- 角色A：脸型 / 发型发色 / 瞳色 / 肤色 / 服装（含换装节点）/ 体态 / 年龄感 + 参考图
- 角色B：…

## 4. 场景锚点
- 场景1：元素清单、光线时段、贯穿道具

## 5. 评分定制（可选）
- 权重覆盖：D1–D6 新权重表（必须合计 100）
- 通过阈值上调：如 pass ≥ 75（仅可上调，见第 4 节）
- 重点镜头清单：hook / 高潮 / 转折镜号（如 EP05-S01），要求从严（扣分加倍）

## 6. 剧目专属检查项
按维度归类的追加检查点，如：
- （D2）古装剧：发饰朝代穿帮、现代内衣外露
- （D5）仙侠剧：法术特效完整性、光效边缘闪烁
- （D6）多集连续剧：跨集服装/伤妆延续

## 7. 红线与禁忌（与通用红线取并集）
- 平台合规：…
- 肖像与商标：…
- 剧情禁忌：如「反派不得使用真实品牌手机」「不得出现真实地标可识别建筑」

## 8. 特殊处理策略
- 台词字幕：烧录字幕是否要求 / 禁止
- 音轨：BGM 禁止或必须、环境音要求
- 多版本镜头：按「同提示词不同模型」还是「不同提示词」对比
- 回写策略：自动回写 / 仅出报告待确认
```

## 4. 合并规则（通用 + 剧目）

| 项 | 规则 |
|---|---|
| 未提供的段 | 完全沿用通用默认（02） |
| 权重（第 5 节） | brief 给出**完整**六维权重表且合计 100 → 整体替换；只给部分 → 与通用权重合并后归一化 |
| 附加检查项（第 6 节） | 按 brief 标注的维度并入该维度清单；未标注维度的归入最相近维度 |
| 红线（第 7 节） | 与通用红线取**并集**；命中任一即 redesign |
| 通过阈值（第 5 节） | **只能上调**（如 75），不得低于后端固定档位 70/60。上调后落入 [70, 75) 的镜头：score 照写、档位按 pass 回写，但 feedback 首行标注 `【低于剧目阈值，建议人工复核】`——后端 verdict 由固定阈值派生（≥70 pass），无法按剧目覆盖，以 feedback 标注补足 |
| 重点镜头（第 5 节） | 命中镜号从严：该镜各维度扣分 ×2 后再汇总 |
| 冲突 | brief 与通用规则冲突时以 brief 为准，并在汇总报告「规范应用说明」记录冲突点 |
| 解析失败/字段非法（如权重合计 ≠100） | 如实降级为通用规则，报告中注明原因，不臆造修正 |

## 5. 生成 brief（用户只有口语化要求时）

1. 加载模板 `assets/review-brief-template.md`。
2. 从用户要求中抽取可填字段；缺口留 `待补充`，**不臆造**（如用户没说画幅，就写 `待确认（默认 9:16）` 并在汇报时提出）。
3. 若剧集目录存在 `shots.md`：全局风格常量（AESTHETIC / MEDIUM / AUDIO / NEGATIVE）、硬性约束、资产绑定说明是现成的定制素材——摘录进第 2、7、8 节并注明「摘自 shots.md」。
4. 生成后展示给用户确认；确认后写入审片对象目录（review_brief.md），后续审片按它执行。
5. 报告「规范应用说明」记录：brief 来源（用户指定 / 本技能生成并经确认 / 未加载）。

## 6. 示例（摘自真实剧目）

《短剧剧本代号奥林匹斯》的 shots.md 头部自带可直接摘录的全局约束：

```markdown
# EP01 拍摄脚本 · The Foal-Born Bastard
> 画幅：9:16 竖屏｜语言：英语对白｜质感：90 年代电视剧（柔光、胶片颗粒、暖饱和）
> 硬性约束：无背景音乐；无字幕；无 Logo；无夸张特效
> AESTHETIC = ethereal Greek mythological aesthetic …
> NEGATIVE  = … extra fingers, deformed hands, bad anatomy, text, watermark, logo, subtitles, modern clothing, background music …
```

据此生成的 brief 第 1/7/8 节（节选）：

```markdown
## 1. 剧目概况
画幅与分辨率：9:16（1080×1920）｜对白语言：英语｜字幕：禁止烧录字幕
单集时长目标：90s（±10%）

## 7. 红线与禁忌（与通用红线取并集）
- 【红线-剧7】出现烧录字幕 / 水印 / Logo（摘自 shots.md 硬性约束）
- 【红线-剧8】出现背景音乐 / 配乐（BGM 由后期统一铺，生成物混入即废）
- 【红线-剧9】现代元素穿帮（现代服装、数字锐化感、HDR 观感——摘自 NEGATIVE）

## 8. 特殊处理策略
- 音轨：必须保留人声与动作/环境音；混入 BGM 判 revise 并在精修提示词中强化 AUDIO 常量
```

> 这就是定制机制的工作方式：**通用规则管「每一镜怎么量」，brief 管「这部剧的尺子上刻了什么」**。
