# 通用审片规则（Generic Review Rules）

> 对应 SKILL.md 索引中的 `references/02-generic-rules.md`。
> 每次审片必加载。包含：六维度检查清单、各维度证据方法、AIGC 瑕疵图鉴、通用红线。
> 剧目定制规则（review_brief.md）在此之上叠加，见 `references/03-drama-brief.md`；冲突时以剧目规范为准。

## 1. 六维度评分模型

每个镜头按六个维度打分（0–100/维度），加权汇总为镜头总分。权重为通用默认值，剧目 brief 可覆盖（见 03 第 4 节）：

| # | 维度 | 默认权重 | 回答的问题 |
|---|---|---|---|
| D1 | 分镜符合度 | 25% | 这条视频拍的是不是这一镜？ |
| D2 | 角色一致性 | 20% | 人是不是同一个人？ |
| D3 | 画面质量 | 15% | 好不好看、稳不稳？ |
| D4 | 运动与物理 | 15% | 动得对不对、自然不自然？ |
| D5 | 技术与瑕疵 | 15% | 有没有明显 AI 瑕疵和技术问题？ |
| D6 | 连续性 | 10% | 和前后镜接不接得上？ |

> 维度设计与 production-orchestrator 的 Video QC / Continuity QC / Story QC 及 ai-video-director 的最终验收（Story / Character / Visual / Motion / AIGC / Continuity）对齐；差异是把「故事正确」落到 D1 的分镜符合度上——初审以单镜为单位，剧集级叙事节拍由制片人终审。

## 2. 各维度检查清单

### D1 分镜符合度（25%）

对照依据：审片条目元数据（`shot_function / script_duration / shot_size / movement / dialogue / source_prompt`）或 shots.md 对应小节。

检查点：

* **主体与动作**：画面主体、核心动作是否为本镜 `镜头功能` 与「秒级动作拆解」描述的动作；有无混入分镜之外的动作。
* **景别与机位**：是否符合 `shot_size`（wide/medium/close-up…）与角度字段；主体落点是否符合构图描述。
* **运镜**：是否符合 `movement`（推/拉/摇/移/固定…）；幅度与方向是否一致。
* **时长**：实际时长 vs `script_duration`。偏差在 ±15% 内不扣；±15–30% 轻扣；>±30% 明显扣分（内容被截断或注水）。
* **场景**：场景元素是否符合 `场景描述` 与场景锚点。
* **台词镜**：若 `dialogue` 非空且 brief 要求口型/字幕（见 03），核对口型开合、情绪与台词是否匹配；brief 未要求时只核对情绪基调。
* **一镜一动作**：单镜承载了多个主要动作 → 记为「动作过载」，这是 redesign 的典型原因（见 04 第 3 节）。

### D2 角色一致性（20%）

对照依据：剧目 brief 的角色外观锚点（03 第 3 节）+ 相邻镜头。

检查点：

* **对锚点**：脸型、发型发色、瞳色、肤色、体态、年龄感、服装与 brief 锚点是否一致（有参考图时对照参考图）。
* **镜内稳定**：首帧 vs 中帧 vs 尾帧，同一角色是否判若两人（面部漂移、发型变化、服装细节丢失）。
* **镜间稳定**：与相邻镜头同一角色是否一致。
* **多角色**：是否串脸（A 的脸出现在 B 身上）、错装、人数错误。

### D3 画面质量（15%）

* **构图**：主体位置、头部空间、视线空间；是否符合构图字段；有无主体出框、地平线歪斜。
* **光感**：光源方向是否自洽；是否符合 `光感` 字段；有无无来由的阴影/高光。
* **色调**：是否符合 `色调` 字段与剧目风格基准；有无整体偏色。
* **清晰度**：焦点是否在主体；有无大面积虚焦、噪点、色彩断层、过锐/涂抹感。
* **技术规格**：分辨率、画幅是否符合 brief 声明的规格（如 9:16 竖屏、1080×1920）。

### D4 运动与物理（15%）

* **动作自然度**：关节、手指、步态、转身、口型是否自然。
* **物理常识**：重力、惯性、接触（落地、持物、碰撞）是否合理；有无漂浮、滑步、穿模。
* **运镜质量**：是否平滑；有无抖动、突然跳变、速度突变、意外变焦。
* **背景稳定性**：背景是否乱漂、蠕动、变形（常见于大幅运镜）。
* **主体一致性**：运动中主体是否变形（面部拉扯、肢体伸长）。

### D5 技术与瑕疵（15%）——AIGC 瑕疵图鉴

逐帧最容易暴露的问题，抽帧时重点看（证据方法见 06 第 4 节）：

| 瑕疵 | 表现 | 典型位置 |
|---|---|---|
| 手部崩坏 | 多指、并指、手指扭转、手持物穿透 | 手部特写、递物动作 |
| 面部融化 | 五官漂移、脸型变化、牙齿/眼睛异常 | 台词镜、转身瞬间 |
| 肢体异常 | 关节反折、四肢数量错误、躯干扭曲 | 全身动作镜 |
| 时间闪烁 | 纹理/光照/服饰细节帧间跳动、整片频闪 | 全片均匀采样可见 |
| 蠕动伪影 | 背景纹理持续蠕动、墙面/地面"融化" | 静止镜头背景 |
| 文字水印 | 乱码、错误字幕、水印 Logo、签名 | 画面角落、字幕区 |
| 冻结/黑帧 | 重复帧、片头片尾黑帧、静止卡顿 | 首尾帧 |
| 硬切残缺 | 动作中突然截断、结束生硬 | 尾帧 |
| 编码问题 | 花屏、马赛克块、色带、抽帧 | 全片 |
| 音轨问题 | 爆音、静音段、BGM 混入（brief 禁止时） | 音频波形/试听 |

### D6 连续性（10%）

与**相邻镜头**（同集按镜号排序的前后镜）对照：

* **人物**：服装、发型、道具持握状态是否衔接。
* **空间**：环境元素（门、桌、窗）位置关系；场景是否跳变。
* **轴线**：对话/运动方向（屏幕左右向）是否跳轴。
* **光线**：光线方向、时段、天气是否一致。
* **情绪**：上一镜结束的情绪状态与下一镜开场是否承接。
* **道具**：道具出现/消失是否无交代。

> 相邻镜缺失时（审片范围内只有孤镜），D6 标注「无相邻镜可比，不计入」并摊权。

## 3. 通用红线（命中任一 → 直接 redesign，≤55 分）

1. **主体身份错误**：画面主体完全不是该镜应有的人物/对象。
2. **内容完全跑偏**：与镜头功能毫无关系（拍的不是这一镜）。
3. **严重崩坏贯穿全片**：面部融化、肢体断裂、大面积闪烁等无法通过同提示词重生成解决的问题。
4. **违规内容**：色情、血腥暴力、真实人物肖像、可识别商标 Logo、政治敏感符号。
5. **时长异常**：<2s 或 >3× script_duration（内容严重截断/注水）。
6. **技术不可用**：无法播放、花屏超过 1/3 时长、无有效画面。

> 剧目 brief 可追加专属红线（题材合规、平台规范、剧情禁忌），红线取并集。命中时 feedback 首行标注 `【红线】` 并引用红线条目号。

## 4. 证据要求

* 每个维度的扣分必须对应至少一个**时间点**（mm:ss）或明确「整片」标注。
* 看片方式与抽帧策略见 `references/06-filesystem-workflow.md` 第 4 节； minimum 采样：首帧、中帧、尾帧 + 每 1–2s 一帧；台词镜、动作镜加密采样。
* 无法确认的问题（疑似但看不清）→ 不作为扣分依据，写入「建议人工复核」。
